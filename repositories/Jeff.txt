# Jeff: Jev-style decision models from open LLMs

Serving code for the **Jeff** decision models: a state, a typed question, and its
options go in, and one forward pass returns a probability for each option. Jeff 1.1 models can also reason before
answering when they are unsure (off by default, see [Reasoning](#reasoning-jeff-11)).

- [New 1.1 suite](https://huggingface.co/collections/jgeuter/jeff-11):
    - [jgeuter/Jeff-1.1-Large](https://huggingface.co/jgeuter/Jeff-1.1-Large) (Backbone: [gemma-4-31B-it](https://huggingface.co/google/gemma-4-31B-it))
    - [jgeuter/Jeff-1.1-Qwen-27B](https://huggingface.co/jgeuter/Jeff-1.1-Qwen-27B) (Backbone: [Qwen3.6-27B](https://huggingface.co/Qwen/Qwen3.6-27B))
    - [jgeuter/Jeff-1.1-Medium](https://huggingface.co/jgeuter/Jeff-1.1-Medium) (Backbone: [gemma-4-12B-it](https://huggingface.co/google/gemma-4-12B-it))
    - [jgeuter/Jeff-1.1-Qwen-4B](https://huggingface.co/jgeuter/Jeff-1.1-Qwen-4B) (Backbone: [Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B))
- [1.0 suite](https://huggingface.co/collections/jgeuter/jeff-10):
    - [jgeuter/Jeff-1.0-Large](https://huggingface.co/jgeuter/Jeff-1.0-Large) (Backbone: [gemma-4-31B-it](https://huggingface.co/google/gemma-4-31B-it))
    - [jgeuter/Jeff-1.0-Qwen-27B](https://huggingface.co/jgeuter/Jeff-1.0-Qwen-27B) (Backbone: [Qwen3.6-27B](https://huggingface.co/Qwen/Qwen3.6-27B))
    - [jgeuter/Jeff-1.0-Medium](https://huggingface.co/jgeuter/Jeff-1.0-Medium) (Backbone: [gemma-4-12B-it](https://huggingface.co/google/gemma-4-12B-it))
    - [jgeuter/Jeff-1.0-Qwen-4B](https://huggingface.co/jgeuter/Jeff-1.0-Qwen-4B) (Backbone: [Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B))
- Technical Report: [Releasing the Inner Jev: A Simple Recipe for Open Decision Models](https://arxiv.org/abs/2610.17205)

## How it works

Each question is rendered as a multiple-choice prompt. A decision head turns the last token's hidden state $h$ into one
logit per option, and a softmax over the $K$ options gives the probabilities:

$$z = c\tanh(W_0 h / c) + A \mathrm{std}(h) + b, \qquad p = \mathrm{softmax}(z_1 / T, \dots, z_K / T),$$

where $W_0$ are the language-model-head rows of the answer letters (A, B, C, ...), $c = 30$ is Gemma's final-logit
soft-capping (Qwen models have none), $\mathrm{std}(h)$ standardizes each feature with statistics computed once on training data, and the
learned correction $A$, $b$ starts at zero, so training starts exactly at the backbone's own letter readout. $T$ is a
temperature per question type (choice, yes/no, score), fitted on our validation data and stored in the model's
`serving_rule.json` (for Jeff-1.1-Large: 1.49 for choice, 1.57 for yes/no, 1.11 for score). Jeff 1.1 models other
than Jeff-1.1-Large read the prompt with bidirectional attention in their full-attention layers, as they were trained
(`"bidirectional": "full"` in `jeff_config.json`).

Question types: `choice`, `noul` (yes/no; the answer is `P(yes)`) and `score` (ordered levels). The head has 16 answer
slots; questions with more options (up to 256) are answered in groups of 16 and a final round between the group
winners. The model reads up to 8,192 tokens. Longer inputs are condensed to at most 8192 tokens; `--long-input refuse` refuses
them instead.

## Run without Docker

```bash
pip install -r requirements.txt && pip install .
jeff-serve jgeuter/Jeff-1.1-Large --revision 970c21af246a44c5527f7109fca129ab6015c941 --host 127.0.0.1 --port 8013
```

On the first start this downloads the weights (about 64 GB) into the Hugging Face cache, which is `~/.cache/huggingface`
unless you set `HF_HOME` (set it to a disk with enough space). `--revision` pins the version we tested; leave it out to
get the newest. Instead of the repo id you can also pass a folder that already holds the weights.

## Run with Docker

The image holds the code and its dependencies, but not the weights. Download the weights first, to any folder with
about 64 GB free (`hf` comes with `pip install huggingface_hub`):

```bash
export JEFF_DIR=$HOME/models/Jeff-1.1-Large          # any folder you like
hf download jgeuter/Jeff-1.1-Large --revision 970c21af246a44c5527f7109fca129ab6015c941 --local-dir "$JEFF_DIR"
docker build -t jeff .
docker run --gpus '"device=0"' -v "$JEFF_DIR":/model:ro -p 127.0.0.1:8013:8013 jeff
python scripts/smoke_test.py --endpoint http://127.0.0.1:8013      # check it
```

Options go after the model folder, e.g. with reasoning on:

```bash
docker run --gpus '"device=0"' -v "$JEFF_DIR":/model:ro -p 127.0.0.1:8013:8013 jeff \
  /model --host 0.0.0.0 --port 8013 --reasoning on
```

For reasoning written by vLLM, build the image with `--build-arg EXTRAS="vllm==0.30.0"` and mount a writable folder at
`/cache` (the base model is rebuilt there once, as large as the model; without the mount it is rebuilt at every start):

```bash
docker build --build-arg EXTRAS="vllm==0.30.0" -t jeff-vllm .
docker run --gpus '"device=0"' -v "$JEFF_DIR":/model:ro -v "$HOME/.cache/jeff":/cache -p 127.0.0.1:8013:8013 jeff-vllm \
  /model --host 0.0.0.0 --port 8013 --reasoning on
```

The container reads the weights from `/model` and needs no network access (it also runs with `--network none`). It
needs one GPU with enough memory (for the 31B and 27B models e.g. H100 80GB, or H200 when reasoning with vLLM); `--gpus` needs the [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/)
on the host.

## Python

```python
from jeff import JeffModel
model = JeffModel("jgeuter/Jeff-1.1-Large")      # or a local folder with the weights; commit=False: calibrated P(yes)
# reasoning=True, think_share=0.3, think_budget=256, long_input="refuse": as the server options
model.decide({"ticket": "Refund not received after 14 days"},
             {"route": {"type": "choice", "instructions": "Which team should handle this?",
                        "criteria": {"billing": "Payments and refunds", "tech": "Technical problems"}}})
```

## Requirements

Tested with Python 3.12, torch 2.13.0 (CUDA 13.0), transformers 5.17.0 and accelerate 1.15.0 (`requirements.txt`).
Without Docker, the machine needs a C compiler (e.g. `gcc`; the image has one): Triton, which torch uses for some GPU
operations, compiles a small helper with it on the first request. The GPU driver must support CUDA 13.0 (R580 or
newer). The Qwen models need nothing extra: without `flash-linear-attention` and `causal-conv1d`, transformers runs their
linear-attention layers with a slower PyTorch implementation.

## Reasoning (Jeff 1.1)

With `--reasoning on`, a question whose calibrated confidence is below a threshold gets a short reasoning
before the answer:

1. the base model (with LoRA off) writes up to 512 tokens (256 for Jeff-1.1-Qwen-4B) of reasoning;
2. the decision model reads the prompt, the reasoning and "Final answer:", and makes a second prediction;
3. that distribution is averaged with the one-pass answer (mean of the log-probabilities) and calibrated with its own temperature.

By default, reasoning is off. If turned on, you can set the share of questions that reasons in two ways:

- `--think-share 0.3` (or `--think-share choice=0.2,noul=0.3,score=0.6`): the thresholds at which this share of questions reasons (measured on validation data), from 0 (never) to 1 (always);
- `--think-threshold 0.8` (or `--think-threshold noul=0.8,score=0.7`): a question reasons when its calibrated
  confidence is below this value.

Limits on reasoning (optional):

- `--think-budget`: sets the maximum tokens per reasoning. Default 512 (256 for Jeff-1.1-Qwen-4B).
- `--max-output-per-decision L`: the mean output tokens per question, over everything the server has answered.
- `--max-think-share S`: no new reasoning while more than a share S of the last 1,000 questions reasoned (after the
  first 100).
- `--request-seconds T`: no new reasoning once a request has taken T seconds.
- `--decision-seconds S`: every question is answered within about S seconds (approximate with vLLM). A reasoning
  that runs out of time stops early and is read as it stands; `--read-partial off` drops it instead.

`--reasoning-config FILE` replaces the model's reasoning
settings with the ones in a JSON file.

The reasoning engine (`--reasoning-engine`) can be set to the following values:

- `auto` (default): vLLM if it is installed (`pip install ".[vllm]"`) and the GPU can hold the model twice, otherwise
  transformers;
- `vllm`: the base model in vLLM, on the same GPU, while the merged model (base+LoRA) runs in `transformers`. `--vllm-base` takes a base model folder or repo id instead. Note you need to fit both the base weights and merged weights in GPU memory;
- `transformers`: no vLLM required. It needs no extra
  memory, and writes about 15 tokens per second on the 31B (69 ms per token; `--fast-reasoning` keeps a second copy of
  the base weights and gets 28 ms).

Note that vLLM rounds differently, so the reasoning text can differ slightly.

## Faster serving (optional)

These options make the server faster on large GPUs.

- `--compile`: compiles the decision forward pass with `torch.compile`. Startup takes a few minutes longer.
- `--fast-reasoning MODE` (with `--reasoning on`): generation uses a static KV cache, which transformers compiles at
  startup. `copy` (the default when no mode is given): the base model that writes the reasoning is kept as a second
  copy of the weights. Roughly doubles reasoning throughput, while also doubling memory. `shared`: no second copy (a
  few GB more memory), somewhat slower than `copy`. `auto`: `copy` when there is room, else `shared`. Prompts over
  4,096 tokens reason uncompiled, so nothing compiles while serving.
- For Qwen models: `pip install flash-linear-attention==0.5.2`: transformers then runs the linear-attention layers
  with these kernels. Use it together with `--compile`.
  

## Batching

Requests that arrive at the same time are answered together (up to `--max-batch` questions, default 32). With vLLM, waiting reasonings also run as one
batch. `--batching off` answers one request at a time.

- Memory: a batch holds at most `--max-batch-tokens` padded input tokens (questions x longest input). By default this
  is set at start from the free GPU memory (about 300,000 tokens for Jeff-1.1-Large on an H200).
- Reproducibility: Padding in batches can change the probabilities by numerical noise (0.004 on average with 8 clients), and vLLM can slightly change probabilities as well. Use `--batching off` to reproduce our numbers exactly.
- Speed: batching helps most for the smaller models and for reasoning. Throughput with 8 clients on one H200, compared
  with one request at a time:

| Model | One pass | With reasoning (vLLM) |
|---|---|---|
| Jeff-1.1-Large | 1.3x | 2.2x |
| Jeff-1.1-Qwen-27B | 1.5x | 1.8x |
| Jeff-1.1-Medium | 1.7x | 2.5x |
| Jeff-1.1-Qwen-4B | 2.5x | 1.5x |

## Request/response format

```
POST /v1/systemone
{"state": {...} or "text",
 "model": "Jeff-1.1-Large",
 "questions": {
   "route":    {"type": "choice", "instructions": "Which team should handle this ticket?",
                "criteria": {"billing": "Payments and refunds", "technical": "Bugs and outages"}},
   "urgent":   {"type": "noul", "instructions": "Does this need a reply today?",
                "criteria": {"true": "Reply today", "false": "Can wait"}},
   "severity": {"type": "score", "instructions": "How severe is the problem?",
                "criteria": ["trivial", "minor", "moderate", "serious", "critical"]}}}
->
{"answers": {"route":    {"type": "choice", "choice": "billing", "probabilities": {"billing": 0.97, "technical": 0.03}},
             "urgent":   {"type": "noul", "noul": 0.801},
             "severity": {"type": "score", "score": 2, "probabilities": {"0": 0.01, "1": 0.2, ...}}},
 "model": "Jeff-1.1-Large", "usage": {"input_tokens": 612, "output_tokens": 0}, "runtime": {...}}
```

Each question is one forward pass (plus a reasoning, if it is on and the question is unsure); the questions of one
request are batched together (one after another with `--batching off`). Instructions and option descriptions that are
not text (objects, lists) are sent to the model as JSON text; an empty state as "(no state was given)". Invalid
requests (and, with `--long-input refuse`, inputs over 8,192 tokens, with a message naming the maximum context length)
get HTTP 422; a failure during the forward pass (for example, out of GPU memory) gets HTTP 500. Both come with
`{"error": "..."}`.

Yes/no answers: JevBench counts $0.2 < P(\text{yes}) < 0.8$ as wrong, so by default the server commits such answers to
0.199 or 0.801 (whichever edge is nearer, as `"urgent"` above). Start it with `--commit off` (Python: `commit=False`) to get
the calibrated $P(\text{yes})$ instead.

# Jeff decision-model server (TypeSafe System One wire format, POST /v1/systemone).
# The CUDA runtime comes with the torch wheel; the host needs an NVIDIA driver for CUDA 13.0 (R580 or newer).
FROM python:3.12-slim
ENV PYTHONUNBUFFERED=1 PIP_NO_CACHE_DIR=1 TOKENIZERS_PARALLELISM=false
WORKDIR /app
# A C compiler: Triton (used by torch for some GPU ops, e.g. in Gemma's rotary embedding) compiles a small driver
# helper with it on the first request. Without it the server fails at its first forward pass.
RUN apt-get update && apt-get install -y --no-install-recommends gcc libc6-dev && rm -rf /var/lib/apt/lists/*
COPY requirements.txt pyproject.toml README.md LICENSE NOTICE ./
COPY src ./src
RUN pip install -r requirements.txt && pip install --no-deps .
# Optional extras, e.g. --build-arg EXTRAS="vllm==0.30.0 flash-linear-attention==0.5.2" for --reasoning-engine vllm and
# the Qwen kernels (see the README). The default image has neither.
ARG EXTRAS=""
RUN if [ -n "$EXTRAS" ]; then pip install $EXTRAS; fi
# vLLM settings, and its caches in /tmp (like torch's)
# the base model rebuilt for vLLM goes to /cache (mount a folder there to keep it between runs)
ENV JEFF_CACHE=/cache
ENV VLLM_NO_USAGE_STATS=1 VLLM_USE_FLASHINFER_SAMPLER=0 VLLM_USE_DEEP_GEMM=0 VLLM_CACHE_ROOT=/tmp/vllm \
    FLASHINFER_WORKSPACE_BASE=/tmp/flashinfer TRITON_CACHE_DIR=/tmp/triton
EXPOSE 8013
# Default: serve a model folder mounted at /model (weights fetched beforehand; works offline).
# Or pass a Hugging Face repo id instead of /model (then the container needs network access).
ENTRYPOINT ["jeff-serve"]
CMD ["/model", "--host", "0.0.0.0", "--port", "8013"]

"""Send three example decisions (choice, yes/no, score) to a running server, print the answers, and compare the
probabilities with the answers we got for the same model (smoke_expected.json next to this script).

    python scripts/smoke_test.py --endpoint http://127.0.0.1:8013

Other GPUs and drivers can shift the probabilities slightly; the check allows --tolerance (default 0.05; across
A100, H100 and RTX PRO 6000 GPUs we saw differences up to about 0.03 on 99% of questions).
"""
import argparse
import json
import sys
import time
import urllib.request
from pathlib import Path

REQUEST = {
    "state": {"ticket": "I was charged twice for order #4411 and want the second charge refunded.",
              "customer_tier": "gold"},
    "model": "Jeff-1.0-Large",
    "questions": {
        "route": {"type": "choice", "instructions": "Which team should handle this ticket?",
                  "criteria": {"billing": "Payments, charges and refunds", "technical": "Bugs and outages",
                               "shipping": "Delivery problems"}},
        "urgent": {"type": "noul", "instructions": "Does this ticket need a reply today?",
                   "criteria": {"true": "A reply is needed today", "false": "It can wait"}},
        "severity": {"type": "score", "instructions": "How severe is the customer's problem?",
                     "criteria": ["trivial", "minor", "moderate", "serious", "critical"]},
    },
}
EXPECTED = Path(__file__).with_name("smoke_expected.json")


def probabilities(answers: dict) -> dict:
    """All probabilities of the answers: {"route/billing": p, ..., "urgent": P(yes), ...}."""
    out = {}
    for key, answer in answers.items():
        if answer["type"] == "noul":
            out[key] = answer["noul"]
        else:
            out.update({f"{key}/{option}": p for option, p in answer["probabilities"].items()})
    return out


if __name__ == "__main__":
    p = argparse.ArgumentParser()
    p.add_argument("--endpoint", default="http://127.0.0.1:8013")
    p.add_argument("--tolerance", type=float, default=0.05, help="largest allowed difference of a probability")
    a = p.parse_args()
    req = urllib.request.Request(a.endpoint.rstrip("/") + "/v1/systemone", data=json.dumps(REQUEST).encode(),
                                 headers={"Content-Type": "application/json"})
    t0 = time.perf_counter()
    with urllib.request.urlopen(req, timeout=120) as r:
        body = json.loads(r.read())
    print(json.dumps(body["answers"], indent=1))
    print(f"input tokens {body['usage']['input_tokens']}, round trip {time.perf_counter() - t0:.3f} s")
    assert set(body["answers"]) == set(REQUEST["questions"]), "missing answers"

    commit = "noul_edge" in body.get("runtime", {}).get("serving_rule", {})
    mode = "commit" if commit else "no-commit"
    reference = json.loads(EXPECTED.read_text()).get(body["model"], {}).get(mode)
    if body.get("runtime", {}).get("reasoned"):
        print(f"{body['runtime']['reasoned']} question(s) reasoned; our reference answers are without reasoning, "
              "so they are not checked (start the server without --reasoning on to check them)")
        sys.exit(0)
    if reference is None:
        print(f"no reference answers for {body['model']} ({mode}); not checked")
        sys.exit(0)
    got, want = probabilities(body["answers"]), probabilities(reference)
    if set(got) != set(want):
        sys.exit(f"FAIL: the answers have other options than our reference: {sorted(set(got) ^ set(want))}")
    worst = max(abs(got[k] - want[k]) for k in want)
    if worst > a.tolerance:
        sys.exit(f"FAIL: a probability differs from our reference by {worst:.4f} (allowed: {a.tolerance})")
    print(f"OK: matches our answers for {body['model']} ({mode}); largest difference {worst:.4f}")

"""Batching for the server (on by default; --batching off serves one question at a time).

The questions of all requests that are waiting are answered together. A worker thread takes the waiting questions (up
to max_batch questions and max_tokens padded input tokens, a cap measured from the GPU's free memory) and runs their
decision passes as one forward pass (Decider.hidden_batch). It never waits for more requests to arrive: a question that
finds the server idle is answered at once, alone. Questions that reason:
- with the vLLM engine, a second thread hands all waiting reasonings to vLLM as one batch while the worker goes on
  answering other questions; the read passes after the reasonings join the worker's next batch;
- with the transformers engine, the worker writes them one after another, after answering the rest of its batch.
A request is answered when all its questions are. With one request at a time (as JevBench sends them) every batch
holds one question and the answers are exactly those of --batching off; with several questions in a batch, the padding
changes the probabilities by numerical noise only (about the size of the effect of --compile).
"""
from __future__ import annotations

import collections
import queue
import threading
import time

from .prompting import MAX_OPTIONS


class Request:
    """One request's questions in flight; done is set when all are answered (or one failed: error)."""

    def __init__(self, keys: list[str], deadline: float | None):
        self.keys, self.left, self.deadline = list(keys), len(keys), deadline
        self.started = time.perf_counter()        # decision_seconds counts from here
        self.answers, self.tokens, self.generated, self.thought, self.seconds = {}, 0, 0, 0, 0.0
        self.dropped = 0                          # reasonings that could not finish in time (one-pass answers)
        self.error = None
        self.done = threading.Event()
        self.lock = threading.Lock()


class Job:
    """One question: stage "first" (the one-pass answer), "read" (after its reasoning) or "wide" (> 16 options)."""

    def __init__(self, request: Request, key: str, question: dict, row: dict):
        self.request, self.key, self.question, self.row = request, key, question, row
        self.ids, self.k, self.stage, self.input_tokens = None, 0, "first", 0
        self.first, self.prompt, self.gen = None, None, None
        self.probs1, self.t1 = None, 0.0           # the one-pass answer and its time (for a dropped reasoning)
        self.admitted = self.counted = False       # reasoning admitted by the limits / its output counted


class Batcher:
    def __init__(self, model, max_batch: int = 32, max_tokens: int | None = None):
        self.model, self.decider = model, model.decider
        self.max_batch = int(max_batch)
        if self.max_batch < 1:
            raise ValueError("max_batch must be at least 1")
        self.max_tokens = int(max_tokens) if max_tokens else self.decider.batch_tokens()
        self.jobs, self.reasonings = queue.Queue(), queue.Queue()
        self.backlog = collections.deque()        # taken from jobs but not yet run (the worker's own)
        self.limits = threading.Lock()            # the reasoner's counts (both threads update them)
        reasoner = self.decider.reasoner
        self.parallel = reasoner is not None and reasoner.generator is not None
        threading.Thread(target=self._work, daemon=True, name="jeff-decide").start()
        if self.parallel:
            threading.Thread(target=self._reason, daemon=True, name="jeff-reason").start()

    def submit(self, state, questions: dict) -> Request:
        """Answer one request; blocks until it is answered. Invalid questions raise at once (before anything runs);
        a failure while answering is raised here too."""
        reasoner = self.decider.reasoner
        rows = [(key, question, self.model.row(state, question, key)) for key, question in questions.items()]
        request = Request([key for key, _, _ in rows], reasoner.request_deadline() if reasoner is not None else None)
        for key, question, row in rows:
            self.jobs.put(Job(request, key, question, row))
        request.done.wait()
        if request.error is not None:
            raise request.error
        return request

    # -- the worker: decision passes ---------------------------------------------------------------------------------

    def _ready(self, job: Job) -> bool:
        """Tokenize a new question (False: it failed or was answered on the spot)."""
        if job.stage != "first" or job.ids is not None:
            return True
        try:
            if len(job.row.get("options") or []) > MAX_OPTIONS:
                self._wide(job)
                return False
            job.row, job.ids, _ = self.decider.prepare(job.row)
            job.k, job.input_tokens = len(job.row["options"]), len(job.ids)
            return True
        except Exception as error:                # noqa: BLE001 - reported to the request
            self._fail(job, error)
            return False

    def _next(self, block: bool) -> Job | None:
        try:
            return self.jobs.get(block=block)
        except queue.Empty:
            return None

    def _take(self) -> list[Job]:
        """The next batch. All waiting questions are taken and sorted by length; a batch holds questions of similar
        length (padding wastes compute: the batch costs batch size x longest input), up to max_batch questions and
        max_tokens padded tokens. The rest wait in the backlog, which is answered before new questions are taken."""
        if not self.backlog:
            waiting = [self._next(block=True)]
            while True:
                job = self._next(block=False)
                if job is None:
                    break
                waiting.append(job)
            ready = [job for job in waiting if self._ready(job)]
            self.backlog.extend(sorted(ready, key=lambda job: len(job.ids)))
            if not self.backlog:
                return []
        batch, width, real = [], 0, 0
        while self.backlog and len(batch) < self.max_batch:
            job = self.backlog[0]
            wider, more = max(width, len(job.ids)), real + len(job.ids)
            if batch and (wider * (len(batch) + 1) > self.max_tokens or wider * (len(batch) + 1) > max(1.25 * more, more + 256)):
                break
            batch.append(self.backlog.popleft())
            width, real = wider, more
        return batch

    def _work(self) -> None:
        torch = self.decider._torch
        while True:
            batch = self._take()
            if not batch:
                continue
            try:
                with torch.inference_mode():
                    start = time.perf_counter()
                    self.decider.cudnn_for(max(len(job.ids) for job in batch))
                    hs = self.decider.hidden_batch([job.ids for job in batch])
                    if self.decider.device.type == "cuda":
                        torch.cuda.synchronize(self.decider.device)
                    share = (time.perf_counter() - start) / len(batch)
                    self._after(batch, hs, share)
            except Exception as error:            # noqa: BLE001 - e.g. out of GPU memory: fail this batch only
                for job in batch:
                    self._release(job)
                    self._fail(job, error)

    def _after(self, batch: list[Job], hs, share: float) -> None:
        reasoner, inline = self.decider.reasoner, []
        for i, job in enumerate(batch):
            h = hs[i: i + 1]
            if job.stage == "read":
                probs, _ = reasoner.read(h, job.k, job.row["qtype"], job.first)
                self._count(job, len(job.gen))
                self._answer(job, probs, len(job.gen), True, share)
                continue
            probs, logits = self.decider.first(h, job.k)
            with self.limits:
                wants = reasoner is not None and reasoner.wants(job.row["qtype"], probs, job.request.deadline)
                job.admitted = wants
            if reasoner is not None and not wants:
                self._count(job, 0)
            if not wants:
                self._answer(job, probs, 0, False, share)
            elif self.parallel:                   # vLLM writes it; the read pass comes back to this worker
                job.first, job.prompt, job.stage = logits, reasoner.prompt(job.ids), "write"
                job.probs1, job.t1 = probs, share
                self.reasonings.put(job)
            else:
                inline.append((job, logits, probs))
        for job, logits, probs1 in inline:        # transformers: after the rest of the batch is answered
            start = time.perf_counter()
            try:
                probs, _, generated, finished = reasoner.think(job.ids, job.k, job.row["qtype"], logits,
                                                               reasoner.decision_end(job.request.started), share)
            except Exception as error:            # noqa: BLE001
                self._release(job)
                self._fail(job, error)
                continue
            self._count(job, generated)
            self._answer(job, probs if finished else probs1, generated, finished, share + time.perf_counter() - start,
                         dropped=not finished)

    def _wide(self, job: Job) -> None:
        """More than 16 options: answered alone, in groups (Decider.decide_wide; these questions do not reason)."""
        with self.decider._torch.inference_mode():
            probs, _, tokens, seconds = self.decider.decide_wide(job.row)
        job.input_tokens = tokens
        self._answer(job, probs, 0, False, seconds)

    # -- the reasoning thread (vLLM) ---------------------------------------------------------------------------------

    def _reason(self) -> None:
        reasoner = self.decider.reasoner
        while True:
            batch = [self.reasonings.get()]
            while True:
                try:
                    batch.append(self.reasonings.get_nowait())
                except queue.Empty:
                    break
            try:
                gens = reasoner.write([job.prompt for job in batch],
                                      [reasoner.decision_end(job.request.started) for job in batch],
                                      [job.t1 for job in batch])
            except Exception as error:            # noqa: BLE001
                for job in batch:
                    self._release(job)
                    self._fail(job, error)
                continue
            for job, (gen, finished) in zip(batch, gens):
                end = reasoner.decision_end(job.request.started)
                if not finished and not reasoner.can_read(job.prompt, gen, end, job.t1):   # the one-pass answer
                    self._count(job, len(gen))
                    self._answer(job, job.probs1, len(gen), False, job.t1, dropped=True)
                    continue
                job.gen, job.ids, job.stage = gen, reasoner.read_ids(job.prompt, gen), "read"
                self.jobs.put(job)

    # -- results -----------------------------------------------------------------------------------------------------

    def _count(self, job: Job, generated: int) -> None:
        """The question is answered: count it (and its output) for the reasoning limits, once."""
        with self.limits:
            if not job.counted:
                self.decider.reasoner.count(generated, job.admitted)
                job.counted = True

    def _release(self, job: Job) -> None:
        """A failed question: release the budget a reasoning held."""
        if self.decider.reasoner is not None and job.admitted:
            self._count(job, 0)

    def _answer(self, job: Job, probs: list[float], generated: int, thought: bool, seconds: float,
                dropped: bool = False) -> None:
        answer = self.model.answer(job.question["type"], [o["id"] for o in job.row["options"]], probs)
        request = job.request
        with request.lock:
            request.answers[job.key] = answer
            request.tokens += job.input_tokens
            request.generated += generated
            request.thought += int(thought)
            request.dropped += int(dropped)
            request.seconds += seconds
            request.left -= 1
            if request.left == 0:
                request.done.set()

    def _fail(self, job: Job, error: Exception) -> None:
        request = job.request
        with request.lock:
            if request.error is None:
                request.error = error
            request.done.set()

"""Bidirectional attention (Jeff 1.1 models whose jeff_config.json has "bidirectional": "full").

The decision is read at the last prompt token and nothing is generated, so the prompt does not have to be read
causally. These models were trained with their full-attention layers reading the prompt in both directions: every
token, including the state, can attend to the question and the option list after it. Gemma 4: the full-attention
layers attend bidirectionally (keys masked only for padding); the sliding-window layers keep their causal sliding mask
(mode "full"); mode "all" also opens the sliding-window layers within their window. Qwen3.5 / 3.6: mode "full" opens
the full-attention layers (one in four); the Gated DeltaNet linear-attention layers are a recurrence and stay causal.
The reasoning (jeff.reasoning) is written by the base model with causal attention (causal()).

    enable(transformer, "full")      # once, after loading: marks the layers, records the mode
    out = transformer(input_ids=ids, attention_mask=attention_arg(transformer, ids, mask), use_cache=False)
"""
from __future__ import annotations

import contextlib

import torch

MODES = (None, "full", "all")


def _check(mode) -> None:
    if mode not in MODES:
        raise ValueError(f"bidirectional must be one of {MODES}, got {mode!r}")


def enable(transformer, mode) -> int:
    """Mark the full-attention layers non-causal; returns how many layers were changed (0 without a mode)."""
    _check(mode)
    if not mode:
        return 0
    types = getattr(transformer.config, "layer_types", None)
    if not types:
        raise ValueError("bidirectional attention needs a model with config.layer_types (Gemma 4)")
    if mode == "all" and "linear_attention" in types:
        raise ValueError("bidirectional='all' is not defined for linear-attention layers (Qwen3.5): use 'full'")
    changed = 0
    for layer, kind in zip(transformer.layers, types):
        if kind == "full_attention" or (mode == "all" and kind == "sliding_attention"):
            layer.self_attn.is_causal = False
            changed += 1
    if not changed:
        raise ValueError("no full-attention layer found")
    transformer._jev_bidirectional = mode
    return changed


@contextlib.contextmanager
def causal(transformer):
    """Temporarily causal again (the base model writes the reasoning); the bidirectional layers and mode are
    restored afterwards."""
    mode = mode_of(transformer)
    if not mode:
        yield
        return
    changed = [layer for layer in transformer.layers                  # Qwen3.5's linear-attention layers have no self_attn
               if getattr(getattr(layer, "self_attn", None), "is_causal", True) is False]
    for layer in changed:
        layer.self_attn.is_causal = True
    transformer._jev_bidirectional = None
    try:
        yield
    finally:
        for layer in changed:
            layer.self_attn.is_causal = False
        transformer._jev_bidirectional = mode


def mode_of(transformer):
    return getattr(transformer, "_jev_bidirectional", None)


def attention_arg(transformer, input_ids: torch.Tensor, attention: torch.Tensor, mode="model"):
    """The attention_mask argument for the decoder stack: the 2D padding mask (no mode), or a dict per layer type.
    mode "model" (default) uses the mode recorded by enable()."""
    mode = mode_of(transformer) if mode == "model" else mode
    _check(mode)
    if not mode:
        return attention
    from transformers.masking_utils import create_bidirectional_mask, create_sliding_window_causal_mask
    config = transformer.config
    batch, width = input_ids.shape
    stub = torch.empty((batch, width, 1), dtype=transformer.dtype, device=input_ids.device)   # shape / dtype / device only
    position_ids = torch.arange(width, device=input_ids.device).unsqueeze(0)
    out = {}
    for kind in set(config.layer_types):
        if kind == "full_attention":
            out[kind] = create_bidirectional_mask(config=config, inputs_embeds=stub, attention_mask=attention)
        elif kind == "linear_attention":     # Qwen3.5 Gated DeltaNet layers: a causal recurrence, padding mask only
            from transformers.masking_utils import create_recurrent_attention_mask
            out[kind] = create_recurrent_attention_mask(config=config, inputs_embeds=stub, attention_mask=attention)
        elif kind == "sliding_attention" and mode == "all":
            window = int(config.sliding_window)
            out[kind] = create_bidirectional_mask(config=config, inputs_embeds=stub, attention_mask=attention,
                                                  and_mask_function=lambda b, h, q, kv: (q - kv).abs() < window,
                                                  allow_is_bidirectional_skip=False)
        elif kind == "sliding_attention":
            out[kind] = create_sliding_window_causal_mask(config=config, inputs_embeds=stub, attention_mask=attention,
                                                          past_key_values=None, position_ids=position_ids)
        else:
            raise ValueError(f"unsupported layer type {kind}")
    return out

"""The Jeff decision head: one logit per answer option from the language model's last hidden state.

    z = c * tanh(W0 h / c) + A std(h) + b,        std(h) = (h - mu) / sigma

h is the post-final-norm hidden state at the last prompt position (what the LM head reads). W0 are the LM-head rows of
the answer letters A-P, so the first term is the model's own letter readout. c is the LM's final-logit soft-capping
(Gemma 4: 30); Qwen models have none, and the first term is then W0 h. mu and sigma were computed once on training
data. The correction A, b was learned; it started at zero, so training started exactly at the letter readout. Slot j
belongs to the option labeled LETTERS[j]; a question with k options uses the first k slots.

Release format: head_config.json and head.safetensors, with fp32 tensors base_rows (W0), delta.weight (A), delta.bias
(b), mu and sigma. The released files also hold an abstain unit (abstain_net.*), used only in training; it never
enters the option probabilities and is not loaded.
"""

from __future__ import annotations

import json
from pathlib import Path

import torch
from torch import nn

from .prompting import MAX_OPTIONS


class DecisionHead(nn.Module):
    def __init__(self, d_model: int, k_slots: int = MAX_OPTIONS, softcap: float | None = None):
        super().__init__()
        self.d_model, self.k_slots = d_model, k_slots
        self.softcap = float(softcap) if softcap else None
        self.register_buffer("base_rows", torch.zeros(k_slots, d_model))
        self.delta = nn.Linear(d_model, k_slots, bias=True)
        self.register_buffer("mu", torch.zeros(d_model))
        self.register_buffer("sigma", torch.ones(d_model))

    def cap(self, z: torch.Tensor) -> torch.Tensor:
        """The LM's final-logit soft-capping (identity without one)."""
        return self.softcap * torch.tanh(z / self.softcap) if self.softcap is not None else z

    def forward(self, h: torch.Tensor) -> torch.Tensor:
        """h [B, d_model] -> logits [B, k_slots]; a question with k options reads the first k."""
        return self.cap(h @ self.base_rows.T) + self.delta((h - self.mu) / self.sigma)


def load_head(folder) -> DecisionHead:
    """The decision head of a released model folder, in fp32."""
    from safetensors.torch import load_file
    folder = Path(folder)
    config = json.loads((folder / "head_config.json").read_text())
    if (config.get("kind") != "residual" or config.get("extra_dim") or config.get("extra_layers")
            or config.get("k_slots") != MAX_OPTIONS):
        raise ValueError(f"{folder}: unsupported decision head {config}")
    head = DecisionHead(config["d_model"], config["k_slots"], config.get("softcap"))
    tensors = load_file(str(folder / "head.safetensors"))
    head.load_state_dict({k: v for k, v in tensors.items() if not k.startswith("abstain_net.")})  # strict
    return head.float()

"""Inputs longer than the model's limit (on by default; --long-input refuse turns it off).

JevBench sends every item to every system, including a few very long states (logs and ledgers of about 80k tokens),
and counts a refused item as wrong. Instead of refusing, the server keeps the parts of the state that matter to the
question. On the long items of our development data this answers far more of them correctly than cutting the state
to its start, and also more than reading the whole input.

No model is involved. The state is split into units and each unit is scored against the question: identifier-like
words of the question (a digit, or an inner . _ - @, e.g. SUP-605069, ACCT-70151, daria.romero, 2026-02-13) count 10
per unit they appear in (as a whole word: ACCT-7015 does not match ACCT-70151), other question words of 5+ letters
count 1; words found in more than a quarter of the units (COMMON) count 0. The highest-scoring units are kept up to
the token budget, in their original order, with a short note that the rest was left out. Units by state shape:
  text with line breaks       lines (the first two lines, usually the header with the rules, are always kept)
  long text without breaks    sentences (the opening ones, up to 400 tokens, always kept); sentences that are still
                              long are split before repeated dates (2026-02-13, records of a flat log) or else into
                              windows of 32 words
  JSON (object or array,      the entries of its largest list or object, or the units of its largest string, going
  or a string holding JSON)   down while one entry holds most of the size; repeated for the next largest part while
                              the state does not fit; all other fields are kept as they are
If no unit mentions the question, or the prompt still does not fit, the state is cut at the token level, keeping its
start. If the question and its options alone do not fit, their texts are shortened too. So a request is never refused
for its length.

plain_state() applies in both modes (since 1.3): a state the prompt format would refuse (empty, a number, NaN inside)
is sent as text, so that every question gets an answer.
"""
from __future__ import annotations

import json
import re

NOTE = "[Only the parts that mention {keys} are shown; {kept} of {total} {unit} kept.]"
CUT = "\n[... cut: the input is too long ...]"
DATE = r"\d{4}-\d{2}-\d{2}"


def question_keys(question: str) -> tuple[set[str], set[str]]:
    """(identifier-like words, other content words) of a question."""
    words = [re.sub(r"'s$", "", w.strip(".,;:?!()[]{}'\"`")) for w in re.findall(r"\S+", question)]
    keys = {w for w in words if len(w) >= 3 and (re.search(r"\d", w) or re.search(r"\w[._@-]\w", w))}
    content = {w.lower() for w in words if len(w) >= 5 and w not in keys and w.isalpha()}
    return keys, content


def _ntok(tokenizer, text: str) -> int:
    return len(tokenizer.encode(text, add_special_tokens=False))


def _prompt_tokens(tokenizer, row, render) -> int:
    return _ntok(tokenizer, render(tokenizer, row))


def _scorer(question: str):
    keys, content = question_keys(question)
    pats = [re.compile(r"(?<![0-9A-Za-z])" + re.escape(k) + r"(?![0-9A-Za-z])") for k in keys]

    def matches(unit: str) -> tuple[list[bool], list[bool]]:
        low = unit.lower()
        return [bool(p.search(unit)) for p in pats], [c in low for c in content]
    return matches


# Question words found in more than this share of the units (e.g. "2026" in a ledger of 2026) select nothing.
COMMON: float | None = 0.25


def select(units: list[str], question: str, tokenizer, budget: int, always: int = 0) -> list[int]:
    """Indices of the units to keep (in order): the first `always` units, then the best-scoring ones within budget."""
    matches = _scorer(question)
    keep = list(range(min(always, len(units))))
    used = sum(_ntok(tokenizer, units[i]) + 1 for i in keep)
    hits = {i: matches(units[i]) for i in range(len(keep), len(units))}
    n_keys = len(next(iter(hits.values()))[0]) if hits else 0
    n_words = len(next(iter(hits.values()))[1]) if hits else 0
    key_w, word_w = [10] * n_keys, [1] * n_words
    if COMMON is not None and hits:
        limit = COMMON * len(hits)
        key_w = [0 if sum(h[0][j] for h in hits.values()) > limit else 10 for j in range(n_keys)]
        word_w = [0 if sum(h[1][j] for h in hits.values()) > limit else 1 for j in range(n_words)]
    scored = []
    for i, (k, w) in hits.items():
        s = sum(a * b for a, b in zip(k, key_w)) + sum(a * b for a, b in zip(w, word_w))
        if s > 0:
            scored.append((-s, i))
    for _, i in sorted(scored):
        n = _ntok(tokenizer, units[i]) + 1
        if used + n > budget:
            continue
        keep.append(i)
        used += n
    return sorted(keep)


def _note(question: str, kept: int, total: int, unit: str) -> str:
    keys, _ = question_keys(question)
    return NOTE.format(keys=", ".join(sorted(keys)) or "the question", kept=kept, total=total, unit=unit)


def _flat_units(text: str, tokenizer, budget: int) -> list[str]:
    """Units of a text without line breaks: sentences; long ones split before repeated dates, else into word windows."""
    cap = max(64, budget // 16)
    out = []
    for sentence in (u for u in re.split(r"(?<=[.!?;])\s+", text) if u):
        if _ntok(tokenizer, sentence) <= cap:
            out.append(sentence)
            continue
        parts = re.split(r"\s+(?=" + DATE + r"\b)", sentence) if len(re.findall(DATE, sentence)) >= 8 else [sentence]
        for part in parts:
            if _ntok(tokenizer, part) <= cap:
                out.append(part)
            else:
                words = part.split(" ")
                out += [" ".join(words[i:i + 32]) for i in range(0, len(words), 32)]
    return out


def _text(text: str, question: str, tokenizer, budget: int) -> tuple[str, int]:
    """(filtered text, number of units kept for matching the question)."""
    if "\n" in text.strip():
        units, sep, always, unit = text.split("\n"), "\n", 2, "lines"
    else:                                   # one long line: sentences; the opening ones (the rules/header) are kept
        units, sep, unit = _flat_units(text, tokenizer, budget), " ", "parts"
        always, used = 1, _ntok(tokenizer, units[0]) if units else 0
        while always < len(units) and used + _ntok(tokenizer, units[always]) <= min(400, budget // 8):
            used += _ntok(tokenizer, units[always])
            always += 1
    if sum(_ntok(tokenizer, units[i]) for i in range(min(always, len(units)))) > budget // 2:
        always = 0                          # a giant header would leave no room for the matching units
    note = _note(question, 0, len(units), unit)
    keep = select(units, question, tokenizer, budget - _ntok(tokenizer, note) - 2, always)
    head = [units[i] for i in keep[:always]]
    rest = [units[i] for i in keep[always:]]
    return sep.join(head + [_note(question, len(keep), len(units), unit)] + rest), len(rest)


# ----------------------------------------------------------------- JSON states

def _dumps(node) -> str:
    return json.dumps(node, ensure_ascii=False)


def _children(node):
    return list(node.items()) if isinstance(node, dict) else list(enumerate(node)) if isinstance(node, list) else []


def _candidates(node, path=()):
    """(size, path) of the parts a filter can shorten: strings, and lists/objects with 2+ entries where no single entry
    holds most of the size (otherwise the filter goes down into that entry)."""
    size = len(_dumps(node))
    out = []
    if isinstance(node, str):
        return [(size, path)]
    kids = _children(node)
    if len(kids) >= 2 and max(len(_dumps(v)) for _, v in kids) < size / 2:
        out.append((size, path))
    for key, child in kids:
        if isinstance(child, (dict, list, str)) and len(_dumps(child)) > 200:
            out += _candidates(child, path + (key,))
    return out


def _get(node, path):
    for key in path:
        node = node[key]
    return node


def _set(node, path, value):
    if not path:
        return value
    _get(node, path[:-1])[path[-1]] = value
    return node


def _filter_part(target, question: str, tokenizer, room: int):
    """(filtered list / object / string, number of entries kept for matching)."""
    if isinstance(target, str):
        return _text(target, question, tokenizer, room)
    kids = _children(target)
    units = [_dumps({k: v}) if isinstance(target, dict) else _dumps(v) for k, v in kids]
    note = _note(question, 0, len(units), "entries")
    keep = select(units, question, tokenizer, room - _ntok(tokenizer, note) - 4)
    note = _note(question, len(keep), len(units), "entries")
    if isinstance(target, dict):
        return {"_note": note, **{kids[i][0]: kids[i][1] for i in keep}}, len(keep)
    return [note] + [kids[i][1] for i in keep], len(keep)


def _json(state, question: str, tokenizer, budget: int) -> tuple[object, int]:
    """(the JSON state with its largest parts filtered until it fits, number of entries kept for matching)."""
    state = json.loads(_dumps(state))                     # private copy
    matched, tried = 0, set()
    for _ in range(8):
        size = _ntok(tokenizer, _dumps(state))
        if size <= budget:
            break
        options = [(s, p) for s, p in _candidates(state) if p not in tried]
        if not options:
            break
        _, path = max(options)
        tried.add(path)
        target = _get(state, path)
        tsize = _ntok(tokenizer, _dumps(target))
        room = max(budget - (size - tsize), budget * tsize // max(1, size))   # what is left, or a fair share
        new, n = _filter_part(target, question, tokenizer, room)
        if n:                                             # nothing matched: leave it, try a smaller part
            state = _set(state, path, new)
            matched += n
    return state, matched


# ----------------------------------------------------------------- fallbacks

def truncate_start(tokenizer, row: dict, limit: int, render, margin: int = 32) -> dict:
    """Last resort: the state as text, cut at the token level (start kept) so that the prompt fits."""
    text = row["state"] if isinstance(row["state"], str) else json.dumps(row["state"], ensure_ascii=False)
    overhead = _prompt_tokens(tokenizer, {**row, "state": "x"}, render)
    ids = tokenizer.encode(text, add_special_tokens=False)
    keep = max(1, limit - overhead - margin)
    out = {**row, "state": tokenizer.decode(ids[:keep]) + CUT}
    while _prompt_tokens(tokenizer, out, render) > limit and keep > 1:
        keep = int(keep * 0.95)
        out = {**row, "state": tokenizer.decode(ids[:keep]) + CUT}
    return out


def squeeze_question(tokenizer, row: dict, limit: int, render) -> dict:
    """The question and option texts cut until they leave at least a quarter of the limit for the state: options keep
    their start (the option id comes first), the question its start and its end (where the actual ask usually is)."""
    def cut(text, n, end=False):
        ids = tokenizer.encode(text, add_special_tokens=False)
        if len(ids) <= n:
            return text
        if end:
            return tokenizer.decode(ids[:n // 2]) + " [...] " + tokenizer.decode(ids[-(n // 2):])
        return tokenizer.decode(ids[:n]) + " [...]"
    n_q, n_o = 2048, 512
    out = row
    while _prompt_tokens(tokenizer, {**out, "state": "x"}, render) > 0.75 * limit and n_o >= 4:
        out = {**row, "question": cut(row["question"], n_q, end=True),
               "options": [{**o, "description": cut(o["description"], n_o)} for o in row["options"]]}
        n_q, n_o = n_q // 2, n_o // 2
    return out


def shorten(tokenizer, row: dict, limit: int, render, margin: int = 96) -> tuple[dict, str]:
    """(row whose rendered prompt fits `limit` tokens, how: "lines" | "parts" | "json" | "cut", plus "+question" when
    the question or option texts were cut too; "question" when only they were).

    The units are counted one by one, but the prompt holds the state JSON-escaped, so the filtered prompt can come out
    a little longer than planned; then the filter runs again with the budget lowered by the overshoot (up to 3 times)."""
    extra = ""
    if _prompt_tokens(tokenizer, {**row, "state": "x"}, render) > 0.75 * limit:
        row, extra = squeeze_question(tokenizer, row, limit, render), "+question"
        if _prompt_tokens(tokenizer, row, render) <= limit:
            return row, "question"                        # the state was short; only the question was too long
    overhead = _prompt_tokens(tokenizer, {**row, "state": "x"}, render)
    budget = limit - overhead - margin
    state = row["state"]
    if isinstance(state, str) and state.lstrip()[:1] in ("{", "["):
        try:
            state = json.loads(state)                     # a string that holds JSON: filtered as JSON, sent as text
        except ValueError:
            pass
    as_text = isinstance(row["state"], str)
    for _ in range(4):
        if budget <= 0:
            break
        if isinstance(state, (dict, list)):
            new, matched = _json(state, row["question"], tokenizer, budget)
            how = "json"
            if as_text:
                new = _dumps(new)
        else:
            text = state if isinstance(state, str) else str(state)
            new, matched = _text(text, row["question"], tokenizer, budget)
            how = "lines" if "\n" in text.strip() else "parts"
        if not matched:
            break
        out = {**row, "state": new}
        n = _prompt_tokens(tokenizer, out, render)
        if n <= limit:
            return out, how + extra
        budget -= (n - limit) + max(16, budget // 20)
    return truncate_start(tokenizer, row, limit, render), "cut" + extra


def plain_state(row: dict) -> dict:
    """A state that the prompt format would refuse (empty, a number, NaN inside) as text."""
    state = row.get("state")
    if isinstance(state, (str, dict, list)) and state:
        try:
            json.dumps(state, allow_nan=False)
            return row
        except ValueError:
            return {**row, "state": json.dumps(state, ensure_ascii=False)}
    if state is None or state == "" or state == [] or state == {}:
        return {**row, "state": "(no state was given)"}
    return {**row, "state": json.dumps(state, ensure_ascii=False)}

"""Load a released Jeff model and answer decisions: by default one forward pass per question, no generation.

A released model folder (or Hugging Face repo) holds the merged weights and tokenizer (standard transformers files),
the decision head (head.safetensors + head_config.json), the serving rule (serving_rule.json) and jeff_config.json.
Each question is rendered as a SemIf-format multiple-choice prompt (options labeled A, B, C, ...; chat template with
thinking disabled), the model reads it once, the head turns the last hidden state into one logit per option, and the
serving rule is applied to the softmax. This computes exactly what we evaluated the released models with.

Since 1.2 (all models):
- inputs over the model's limit (8,192 tokens) keep their question-relevant parts instead of being refused, and states
  the prompt format cannot hold (empty, a bare number) are sent as text (jeff.longinput; long_input="refuse" refuses
  long inputs instead; since 1.3 it still sends such states as text);
- questions with more than 16 options (up to 256) are answered in groups of 16 and a final round between the group
  winners (Decider.decide_wide).
Jeff 1.1 models also have
- bidirectional attention (jeff_config.json "bidirectional"; jeff.bidir), as they were trained;
- reasoning when unsure (reasoning.json and adapter/; jeff.reasoning), off by default (reasoning=True turns it on).

    from jeff import JeffModel
    model = JeffModel("jgeuter/Jeff-1.0-Large")
    model.decide({"ticket": "Refund not received after 14 days"},
                 {"route": {"type": "choice", "instructions": "Which team should handle this?",
                            "criteria": {"billing": "Payments and refunds", "tech": "Technical problems"}}})
"""

          "options": [{"id": "true", "description": "true: yes"}, {"id": "false", "description": "false: no"}]}

def disable_cudnn_attention() -> None:
    """Turn off PyTorch's cuDNN attention kernel for this process.

    cuDNN attention builds a new execution plan for every new input shape, and served requests almost always have a
    new length. For Gemma 4 31B this costs about 2x per request on H200 (0.123 s vs 0.061 s median on our validation
    items) and up to 10x on H100 with torch 2.11 (0.72 s vs 0.07 s); answers do not change. The flash and
    memory-efficient kernels have no per-shape cost. Very long inputs are the exception, so the Decider turns cuDNN
    back on from CUDNN_MIN_TOKENS tokens.
    """
    import torch
    torch.backends.cuda.enable_cudnn_sdp(False)


def model_folder(ref: str | Path, revision: str | None = None) -> Path:
    """A local folder, or a snapshot of a Hugging Face model repo (downloaded once, then cached)."""
    path = Path(ref).expanduser()
    if path.is_dir():
        return path
    text = str(ref)
    if text.startswith((".", "/", "~")) or text.count("/") != 1:   # a path, not a Hugging Face repo id like org/name
        raise FileNotFoundError(f"model folder not found: {text}. Download the weights first, e.g. "
                                f"`hf download jgeuter/Jeff-1.1-Large --local-dir {text}`, or pass a repo id.")
    from huggingface_hub import snapshot_download
    return Path(snapshot_download(text, revision=revision))


def load_causal_model(folder: Path, device: str = "cuda", dtype: str = "bfloat16"):
    import torch
    import transformers
    common = {"local_files_only": True, "trust_remote_code": False}
    config = transformers.AutoConfig.from_pretrained(folder, **common)
    tokenizer = transformers.AutoTokenizer.from_pretrained(folder, **common)
    model, loading = transformers.AutoModelForCausalLM.from_pretrained(
        folder, config=config, dtype=getattr(torch, dtype), device_map={"": device}, low_cpu_mem_usage=True,

    if any(loading.get(key) for key in ("missing_keys", "mismatched_keys", "error_msgs")):
        raise RuntimeError(f"Checkpoint did not load completely: {loading}")
    return model.eval(), tokenizer


class Decider:
    """One model + head; decide(row) -> option probabilities, option logits, input tokens, seconds. After each call,
    `last` holds {"output_tokens", "thought", "dropped", "shortened"} for that decision (dropped: a reasoning that
    could not finish within decision_seconds; the answer is the one pass)."""

    def __init__(self, model, tokenizer, head, max_tokens: int = MAX_TOKENS, bidirectional: str | None = None,
                 long_input: str = "filter"):
        import torch
        if long_input not in LONG_INPUT:
            raise ValueError(f"long_input must be one of {LONG_INPUT}, got {long_input!r}")
        self.model, self.tokenizer, self.max_tokens = model, tokenizer, max_tokens
        self.base = getattr(model, "model", model)
        self.device = next(model.parameters()).device
        self.head = head.to(self.device).eval()
        self._torch = torch
        self.cudnn_min_tokens = None   # set: cuDNN attention only for inputs this long (see disable_cudnn_attention)
        self.bidirectional = bidirectional
        if bidirectional:
            from . import bidir
            bidir.enable(self.base, bidirectional)
        self.long_input = long_input
        self.reasoner = None           # a jeff.reasoning.Reasoner when reasoning is on
        self.forward = self.base       # the decision forward pass; compile() swaps in a compiled one
        self.last = {"output_tokens": 0, "thought": False, "dropped": False, "shortened": False}

    def hidden(self, ids: list[int]):
        """Post-final-norm hidden state at the last position (with bidirectional masks for such models)."""
        torch = self._torch
        x = torch.tensor([ids], device=self.device)
        mask = None
        if self.bidirectional:
            from .bidir import attention_arg
            mask = attention_arg(self.base, x, torch.ones_like(x))
        return self.forward(input_ids=x, attention_mask=mask, use_cache=False, return_dict=True).last_hidden_state[:, -1]

    def hidden_batch(self, batch: list[list[int]]):
        """hidden() for several inputs in one forward pass [B, d]: right-padded, so every input keeps its positions and
        (with the padding masked) attends to what it attends to alone; the results differ from hidden() by numerical
        noise only (about the size of the effect of --compile). One input: exactly hidden()."""
        torch = self._torch
        if len(batch) == 1:
            return self.hidden(batch[0])
        width = max(len(ids) for ids in batch)
        pad = self.tokenizer.pad_token_id if self.tokenizer.pad_token_id is not None else 0
        x = torch.tensor([ids + [pad] * (width - len(ids)) for ids in batch], device=self.device)
        attention = torch.tensor([[1] * len(ids) + [0] * (width - len(ids)) for ids in batch], device=self.device)
        if self.bidirectional:
            from .bidir import attention_arg
            mask = attention_arg(self.base, x, attention)
        else:
            mask = attention
        out = self.forward(input_ids=x, attention_mask=mask, use_cache=False, return_dict=True).last_hidden_state
        last = torch.tensor([len(ids) - 1 for ids in batch], device=self.device)
        return out[torch.arange(len(batch), device=self.device), last]

    def compile(self) -> None:
        """Compile the decision forward pass with torch.compile (one graph for all input lengths). About 30-40% less
        time per decision on an H200; probabilities change by numerical noise only (fused kernels round differently),
        of the same size as changing the input's padding. The first calls compile (a few minutes for the 31B)."""
        import torch._inductor.config as inductor
        inductor.emulate_precision_casts = True     # round intermediate results as eager mode does: closer answers
        self.forward = self._torch.compile(self.base, dynamic=True)

    def start_request(self) -> None:
        """A new request (the reasoning's per-request time limit starts now)."""
        if self.reasoner is not None:
            self.reasoner.start_request()

    def decide(self, row: dict) -> tuple[list[float], list[float], int, float]:
        if isinstance(row.get("options"), list) and len(row["options"]) > MAX_OPTIONS:
            return self.decide_wide(row)
        return self._decide(row)

    def decide_wide(self, row: dict) -> tuple[list[float], list[float], int, float]:
        """More options than the head has slots (JevBench allows up to 255): score the options in groups of at most 16
        (as equal in size as possible, so none has a single option), then the group winners against each other; an option's probability is P(its group's winner wins the final) x P(it
        within its group). Sums to 1. These questions do not reason."""
        row = plain_state(row)                    # an empty or numeric state as text, as in prepare()
        validate_row(row, MAX_WIDE)
        options = row["options"]
        groups = split_groups(len(options), MAX_OPTIONS)
        inner, winners, tokens, seconds = [], [], 0, 0.0
        reasoner, self.reasoner = self.reasoner, None
        try:
            for g in groups:
                probs, _, n, t = self._decide({**row, "options": [options[i] for i in g]})
                inner.append(probs)
                winners.append(g[max(range(len(g)), key=probs.__getitem__)])
                tokens, seconds = tokens + n, seconds + t
            final, _, n, t = self._decide({**row, "options": [options[i] for i in winners]})
        finally:
            self.reasoner = reasoner
        probs = [0.0] * len(options)
        for gi, g in enumerate(groups):
            for j, i in enumerate(g):
                probs[i] = final[gi] * inner[gi][j]
        self.last["groups"] = len(groups)
        return probs, [math.log(max(p, 1e-30)) for p in probs], tokens + n, seconds + t

    def prepare(self, row: dict) -> tuple[dict, list[int], str | bool]:
        """(row as read, its prompt token ids, how it was shortened or False): long inputs filtered, states the
        prompt cannot hold sent as text (long_input "filter")."""
        if self.reasoner is not None and row.get("qtype") not in ("choice", "noul", "score"):
            raise ValueError("reasoning needs the question type in the row (qtype: choice, noul or score)")
        row = plain_state(row)                    # in both modes: an empty or numeric state is sent as text
        try:
            return row, encode_prompt(self.tokenizer, row, self.max_tokens), False
        except ValueError as error:
            if self.long_input != "filter" or "exceed limit" not in str(error):
                raise
            row, how = shorten(self.tokenizer, row, self.max_tokens, render_prompt)
            return row, encode_prompt(self.tokenizer, row, self.max_tokens), how

    def cudnn_for(self, tokens: int) -> None:
        if self.cudnn_min_tokens is not None:
            self._torch.backends.cuda.enable_cudnn_sdp(tokens >= self.cudnn_min_tokens)

    def first(self, h, k: int) -> tuple[list[float], list[float]]:
        """(probabilities, logits) of the one-pass answer from the last hidden state h [1, d]."""
        torch = self._torch
        logits = self.head(h.to(torch.bfloat16).float())[0, :k]     # bfloat16 h, as in our evaluations
        return torch.softmax(logits, dim=-1).tolist(), logits.tolist()

    def _decide(self, row: dict) -> tuple[list[float], list[float], int, float]:
        torch = self._torch
        self.last = {"output_tokens": 0, "thought": False, "dropped": False, "shortened": False}
        reasoner = self.reasoner
        row, ids, self.last["shortened"] = self.prepare(row)
        self.cudnn_for(len(ids))
        start = time.perf_counter()
        k = len(row["options"])
        with torch.inference_mode():
            probs, logits = self.first(self.hidden(ids), k)
            if reasoner is not None:
                admitted = reasoner.wants(row["qtype"], probs)
                if admitted:
                    t1 = time.perf_counter() - start            # the one pass (its .tolist() waited for the GPU)
                    p, z, generated, finished = reasoner.think(ids, k, row["qtype"], logits, reasoner.decision_end(), t1)
                    if finished:
                        probs, logits = p, z
                    self.last.update(output_tokens=generated, thought=finished, dropped=not finished)
                reasoner.count(self.last["output_tokens"], admitted)
        if self.device.type == "cuda":
            torch.cuda.synchronize(self.device)
        return probs, logits, len(ids), time.perf_counter() - start

    def batch_tokens(self, reserve: float = 0.05, min_reserve_bytes: int = 2 << 30) -> int:
        """How many padded input tokens (batch size x longest input) one forward pass can take on this GPU: the free
        memory (minus a reserve of 5% of the GPU, at least 2 GB) over the peak memory per token of a forward pass on
        an input of the model's full length. Measured once (the server calls it after loading, with vLLM's share
        already taken); never below one full-length input."""
        torch = self._torch
        if self.device.type != "cuda":
            return 4 * self.max_tokens
        ids = [self.tokenizer.pad_token_id or 0] * self.max_tokens
        torch.cuda.synchronize(self.device)
        free, total = torch.cuda.mem_get_info(self.device)
        free += torch.cuda.memory_reserved(self.device) - torch.cuda.memory_allocated(self.device)
        torch.cuda.reset_peak_memory_stats(self.device)
        before = torch.cuda.memory_allocated(self.device)
        with torch.inference_mode():
            self.hidden(ids)
        torch.cuda.synchronize(self.device)
        per_token = max(torch.cuda.max_memory_allocated(self.device) - before, 1) / len(ids)
        usable = free - max(reserve * total, min_reserve_bytes)
        return max(self.max_tokens, int(usable / per_token))


def split_groups(n: int, size: int) -> list[list[int]]:
    """Indices 0..n-1 in consecutive groups of at most `size`, as equal in size as possible (17 -> 9 + 8)."""
    count = -(-n // size)
    bounds = [round(i * n / count) for i in range(count + 1)]
    return [list(range(bounds[i], bounds[i + 1])) for i in range(count)]


def served_answer(qtype: str, option_ids: list[str], probabilities: list[float], rule: dict) -> dict:
    """TypeSafe answer object with the serving rule applied (identity without a rule)."""
    out = T.answer(qtype, option_ids, probabilities)
    if not rule:
        return out
    if qtype == "noul":
        return {"type": "noul", "noul": T.apply_rule("noul", {"yes": out["noul"], "no": 1 - out["noul"]}, rule)["yes"]}
    probs = T.apply_rule(qtype, out["probabilities"], rule)
    best = max(option_ids, key=lambda i: probs[i])
    return {**out, qtype: best if qtype == "choice" else int(best), "probabilities": probs}


class JeffModel:
    """commit (default True): the yes/no commitment of the released serving rule. JevBench counts a yes/no answer with
    0.2 < P(yes) < 0.8 as wrong, so the rule moves such answers to just outside the nearer edge (0.801 or 0.199).
    commit=False keeps the calibrated P(yes) (temperatures still apply).

    long_input: "filter" (default) or "refuse" (see the module docstring).

    reasoning (default False; Jeff 1.1 models): reason when unsure (jeff.reasoning). With it: jevbench_limits (default
    False) applies the limits we evaluate on JevBench with; think_share (a number, or {type: share}) and think_budget
    override the released share of questions that reason and the most tokens a reasoning may take; think_threshold (a
    number, or {type: threshold}) sets confidence thresholds directly; max_output_per_decision, max_think_share,
    request_seconds and decision_seconds set those limits on their own; reasoning_config (a dict or JSON file) replaces
    reasoning.json's budget, read, pooling, temperatures, shares or JevBench limits (jeff.reasoning.read_config);
    read_partial: read a reasoning cut by decision_seconds instead of dropping it (default: the config's, else on).

    reasoning_engine: what writes the reasoning. "transformers": this model, with the adapter removed by hooks (or a
    second weight copy, see fast_reasoning); "vllm": the base model in vLLM on the same GPU, rebuilt from this release
    once (jeff.reasoning.derive_base, under cache_dir) unless vllm_base names one; "auto" (default): vLLM if it is
    installed and the GPU can hold the model twice, else transformers. vllm_seqs: how many reasonings vLLM writes at
    once.

    fast_reasoning (transformers engine): "off" (False, default): hooks, a dynamic KV cache; "copy" (True): a second
    copy of the adapted layers' weights and a static KV cache, which transformers compiles (the hooks when the GPU has
    no room for the copy); "shared": the hooks with a static KV cache, compiled, so no second copy is needed; "auto":
    copy when there is room, else shared."""

    def __init__(self, ref: str | Path, revision: str | None = None, device: str = "cuda",
                 rule: dict | None = None, cudnn_attention: bool = False, commit: bool = True,
                 long_input: str = "filter", reasoning: bool = False, jevbench_limits: bool = False,
                 think_share: float | dict | None = None, think_budget: int | None = None,
                 max_output_per_decision: float | None = None, request_seconds: float | None = None,
                 compile: bool = False, fast_reasoning: bool | str = False, reasoning_engine: str = "auto",
                 vllm_memory: float | None = None, vllm_base: str | None = None, vllm_seqs: int = 1,
                 think_threshold: float | dict | None = None, max_think_share: float | None = None,
                 cache_dir: str | Path | None = None, decision_seconds: float | None = None,
                 reasoning_config: str | Path | dict | None = None, read_partial: bool | None = None):
        from . import bidir
        folder = model_folder(ref, revision)
        self.folder = folder
        self.config = json.loads((folder / "jeff_config.json").read_text())
        self.name = self.config.get("name", folder.name)
        for key, supported in (("prompt_version", PROMPT_VERSION), ("noul_mapping", "tf-true-first")):
            if self.config.get(key, supported) != supported:

                                      threshold=think_threshold, max_output_per_decision=max_output_per_decision,
                                      max_share=max_think_share, request_seconds=request_seconds,
                                      decision_seconds=decision_seconds, config=reasoning_config,

        if not commit:

            raise ValueError(f"reasoning_engine must be auto, transformers or vllm, got {reasoning_engine!r}")

            self.decider.compile()

            self.decider.reasoner = Reasoner(self.decider, self.reasoning, None, self.rule, generator=generator)
        elif self.reasoning is not None:
            from .reasoning import LoraDelta, Reasoner
            copy = fast in ("copy", "auto") and LoraDelta.copy_fits(model, folder / "adapter")
            shared = fast == "shared" or (fast == "auto" and not copy)
            if fast in ("copy", "auto") and not copy:
                print(f"--fast-reasoning: not enough GPU memory for a second copy of the weights; using the hooks"
                      f"{' (compiled, shared weights)' if shared else ''}", flush=True)
            self.fast_reasoning = "copy" if copy else ("shared" if shared else False)
            self.decider.reasoner = Reasoner(self.decider, self.reasoning, LoraDelta(model, folder / "adapter", copy=copy),
                                             self.rule, static_cache=copy or shared)

    def warmup(self, times: int = 3, batch: bool = False) -> None:
        """A few forward passes (kernels, allocator; with compile: the compiled graphs, for short and long inputs, and
        with batch also for batches), without reasoning and not counted by its limits."""
        reasoner, self.decider.reasoner = self.decider.reasoner, None
        try:
            for i in range(times):
                self.decider.decide(WARMUP)
            if self.decider.forward is not self.decider.base:
                for words in (60, 600, 1500):
                    self.decider.decide({**WARMUP, "state": "The sky is blue. " * words})
            if batch:
                rows = [self.decider.prepare({**WARMUP, "state": "The sky is blue. " * words})[1] for words in (5, 60)]
                with self.decider._torch.inference_mode():
                    for n in (2, 3):
                        self.decider.hidden_batch((rows * 2)[:n])
            if reasoner is not None and (reasoner.static_cache or reasoner.generator is not None):
                # --fast-reasoning: transformers compiles the decoding step on first use (minutes for the 31B; once:
                # one static cache size for all prompts, STATIC_PROMPT_TOKENS); do it now, not on the first request
                for words in (5, 120, 600):
                    try:
                        ids = encode_prompt(self.decider.tokenizer, {**WARMUP, "state": "The sky is blue. " * words},
                                            self.decider.max_tokens)
                    except ValueError:                     # longer than this model's input limit: skip this length
                        continue
                    with self.decider._torch.inference_mode():
                        reasoner.think(ids, 2, "noul", [0.0, 0.0])
        finally:
            self.decider.reasoner = reasoner

    def row(self, state, question: dict, key: str = "q") -> dict:
        return T.question_row(state, question, key)

    def answer(self, qtype: str, option_ids: list[str], probabilities: list[float]) -> dict:
        return served_answer(qtype, option_ids, probabilities, self.rule)

    def decide(self, state, questions: dict) -> dict:
        """TypeSafe request: state + {name: {type, instructions, criteria}} -> {name: answer}."""
        self.decider.start_request()
        answers = {}
        for key, question in questions.items():
            row = self.row(state, question, key)
            probs, _, _, _ = self.decider.decide(row)
            answers[key] = self.answer(question["type"], [o["id"] for o in row["options"]], probs)
        return answers

"""Prompts for decision rows, in the format of SemIf (github.com/TheoLeeCJ/SemIf, MIT).

A row is {"id": str, "state": str | dict | list, "question": str, "options": [{"id": str, "description": str}, ...]}
with 2 to 16 options (jeff.model answers questions with up to 256 options in groups of 16). Score questions use the
same format: the ordered levels are the options.

The prompt is SemIf's: a system message, then the row as a JSON object {evidence, criterion, options} with the options
labeled A, B, C, ..., rendered with the model's chat template with thinking disabled. Jeff models were trained and
evaluated with exactly this prompt (PROMPT_VERSION). It is byte-identical to SemIf's; we checked this against the
prompt hashes (prompt_sha256) in SemIf's published prediction files.
"""

from __future__ import annotations

import json

LETTERS = "ABCDEFGHIJKLMNOP"
MAX_OPTIONS = len(LETTERS)  # the decision head has one slot per letter
MAX_WIDE = MAX_OPTIONS * MAX_OPTIONS  # most options of a question answered in groups (jeff.model.Decider.decide_wide)
PROMPT_VERSION = "direct-options-v1"
DIRECT_SYSTEM = (
    "Apply the supplied criterion to the supplied evidence. Choose exactly one listed option. "
    "Respond with only its uppercase letter, with no explanation or reasoning."
)


def validate_row(row: dict, max_options: int = MAX_OPTIONS) -> None:
    required = {"id", "state", "question", "options"}
    if not required <= row.keys():
        raise ValueError(f"Row is missing fields: {sorted(required - row.keys())}")
    if not all(isinstance(row[key], str) and row[key] for key in ("id", "question")):
        raise ValueError("id and question must be nonempty strings")
    state = row["state"]
    if not isinstance(state, (str, dict, list)) or not state:
        raise ValueError("state must be a nonempty string, object, or array")
    try:
        json.dumps(state, ensure_ascii=False, allow_nan=False)
    except (TypeError, ValueError) as error:
        raise ValueError("state must be finite JSON-compatible data") from error
    options = row["options"]
    if not isinstance(options, list) or not 2 <= len(options) <= max_options:
        raise ValueError(f"options must contain 2-{max_options} entries")
    ids = []
    for option in options:
        if not isinstance(option, dict) or not isinstance(option.get("id"), str) or not isinstance(option.get("description"), str):
            raise ValueError("Each option needs string id and description fields")
        ids.append(option["id"])
    if len(ids) != len(set(ids)):
        raise ValueError("Option IDs must be unique")


def messages(row: dict) -> list[dict]:
    """Chat messages of a row: SemIf's system message, then the row as JSON."""
    validate_row(row)
    payload = {
        "evidence": row["state"],
        "criterion": row["question"],
        "options": [
            {"letter": LETTERS[index], "description": option["description"]}
            for index, option in enumerate(row["options"])
        ],
    }
    return [
        {"role": "system", "content": DIRECT_SYSTEM},
        {"role": "user", "content": json.dumps(payload, ensure_ascii=False)},
    ]


def render_prompt(tokenizer, row: dict) -> str:
    return tokenizer.apply_chat_template(
        messages(row), tokenize=False, add_generation_prompt=True, enable_thinking=False
    )


def encode_prompt(tokenizer, row: dict, max_tokens: int) -> list[int]:
    """Token ids of a row's prompt. Rows longer than max_tokens are rejected, not truncated (as in SemIf)."""
    ids = tokenizer.encode(render_prompt(tokenizer, row), add_special_tokens=False)
    if not ids or len(ids) > max_tokens:
        raise ValueError(f"Row {row['id']}: {len(ids)} input tokens exceed limit {max_tokens} (the maximum context length); "
                         "no truncation allowed")
    return ids

"""Reasoning when unsure (Jeff 1.1 models; off by default, `--reasoning on`).

Every question is first answered in one forward pass, as without reasoning. If the calibrated confidence of that answer
(its largest probability at the serving rule's temperature) is below a threshold for the question's type, the question
gets a short reasoning:
1. the base model writes up to `budget` tokens greedily, with causal attention, after the prompt and the opener
   "Let me check the deciding facts first.". The base model is the released weights minus the LoRA adapter, which
   ships in adapter/ for this (LoraDelta);
2. the decision model (the released weights) reads the prompt, the reasoning and "\\n\\nFinal answer:", and the answer
   is read from its letter logits at that position (the LM's logits of the option letters, bare and with a space);
3. that distribution is pooled with the one-pass answer (mean of the log-probabilities) and calibrated with its own
   temperature per type. It replaces the one-pass answer; the yes/no commitment of the serving rule still applies.
The generated tokens are reported as output tokens.

Which questions reason: for a think share s of a type, the threshold is the s-quantile of the calibrated one-pass
confidences on our own validation questions of that type (reasoning.json "tau_table", steps of 0.01), so about a share
s of similar questions reason (on other data the share can differ). The released shares are the ones we selected on
held-out data; `--think-share` picks others (0: never, 1: always). `--think-threshold` sets the confidence threshold
of a type directly instead (a question reasons when its calibrated confidence is below it).

Limits (all off unless set; `--jevbench-limits on` sets the ones we evaluate on JevBench with, so that the model stays
within the board's cost and latency caps):
- max_output_per_decision L: a question reasons only if (output tokens so far + budget) / (questions so far + 1) <= L,
  counted over everything this server has answered. The mean output per question therefore never exceeds L, whatever
  the share of unsure questions. Questions still reasoning count with the full budget until they finish;
- max_share (`--max-think-share`): no new reasoning while more than this share of the last `window` questions reasoned
  (after `warmup` questions); this keeps the median latency at one forward pass;
- request_seconds: no new reasoning once a request has taken this long, so a request with many questions stays bounded;
- decision_seconds S (`--decision-seconds`): every question of a request is answered within about S seconds of the
  request's arrival. A question reasons only if its one pass leaves time; the generation stops when the next token and
  the read after it would end later than S (the read time is estimated from the measured prefill time), and such a
  cut reasoning is read as it stands, as if it had ended at its budget (read_partial, the default; with
  `--read-partial off` it is dropped: the question keeps its one-pass answer, and its generated tokens still count as
  output). So a slower GPU only means fewer finished (or shorter) reasonings. With the vLLM engine the limit is a token
  cap from the measured speed, so it is approximate there.
Without limits, every question below its threshold reasons.
"""
from __future__ import annotations

import collections
import contextlib
import hashlib
import json
import math
import os
import shutil
import time
from pathlib import Path

TYPES = ("choice", "noul", "score")
LIMITS = ("max_output_per_decision", "max_share", "request_seconds", "decision_seconds")
# JevBench (method v1.7) counts a decision that takes more than 10 s as failed; --jevbench-limits leaves a margin for
# the request's way in and out and for a slow step (one reasoning step took 0.7 s once in our tests)
JEVBENCH_DEFAULTS = {"decision_seconds": 8.5}


def per_type(value, name: str) -> dict:
    """{type: value} from one number (every type) or a {type: number} dict."""
    out = dict(value) if isinstance(value, dict) else {q: value for q in TYPES}
    unknown = set(out) - set(TYPES)
    if unknown:
        raise ValueError(f"{name} for unknown question types {sorted(unknown)}")
    for q, v in out.items():
        if not 0.0 <= float(v) <= 1.0:
            raise ValueError(f"{name} must be between 0 and 1, got {v} for {q}")
    return {q: float(v) for q, v in out.items()}


CONFIG_KEYS = ("budget", "read", "mix", "temperatures", "share", "jevbench_limits", "read_partial")

# --fast-reasoning: the static KV cache has one size, prompts up to this many tokens plus the budget, so transformers
# compiles the decoding step once (at warm-up) and never while serving (a larger size compiled again inside the
# request: on the 31B, a 6,100-token prompt's reasoning took 8.5 s instead of 4.8 s). A longer prompt reasons without
# it: a dynamic cache, not compiled (the speed of --fast-reasoning off).
STATIC_PROMPT_TOKENS = 4096


def read_config(config) -> dict:
    """A reasoning config (--reasoning-config): a dict or a JSON file with some of CONFIG_KEYS, checked."""
    out = json.loads(Path(config).read_text()) if isinstance(config, (str, Path)) else dict(config)
    unknown = sorted(set(out) - set(CONFIG_KEYS))
    if unknown:
        raise ValueError(f"reasoning config: unknown keys {unknown} (allowed: {', '.join(CONFIG_KEYS)})")
    if out.get("read", "letters") not in ("letters", "head"):
        raise ValueError(f"reasoning config: read must be letters or head, got {out['read']!r}")
    for q, t in out.get("temperatures", {}).items():
        if q not in TYPES or not float(t) > 0:
            raise ValueError(f"reasoning config: temperatures need a positive value per type, got {q}: {t}")
    if "share" in out:
        out["share"] = {**per_type(out["share"], "think share")}
    if "budget" in out and int(out["budget"]) < 1:
        raise ValueError("the think budget must be at least 1 token")
    return out


def settings(folder, share=None, budget: int | None = None, jevbench_limits: bool = False, threshold=None,
             config=None, read_partial: bool | None = None, **limits) -> dict:
    """The reasoning settings of a model folder (reasoning.json), with overrides.

    config: a dict or JSON file whose keys (CONFIG_KEYS) replace reasoning.json's (jevbench_limits: merged), e.g. the
    budget, read, pooling ("mix"), temperatures and shares chosen for a deployment; the other arguments apply on top.
    share: None (the released shares), one number for all types, or {type: share}. threshold: None, one number or
    {type: confidence threshold}, used directly instead of a share's threshold (a type cannot have both). limits:
    values for LIMITS (None = not given); with jevbench_limits, the released value of every limit that is not given."""
    path = Path(folder) / "reasoning.json"
    if not path.is_file():
        raise ValueError(f"{folder}: this model has no reasoning settings (reasoning.json); Jeff 1.0 models answer in "
                         "one forward pass only")
    config, given_config = json.loads(path.read_text()), read_config(config) if config is not None else {}
    for key, value in given_config.items():
        if key == "jevbench_limits":
            config[key] = {**config[key], **value}
        elif key in ("temperatures", "share"):
            config[key] = {**config[key], **value}
        else:
            config[key] = value
    given = per_type(share, "think share") if share is not None else {}
    fixed = per_type(threshold, "think threshold") if threshold is not None else {}
    both = sorted(set(given) & set(fixed))
    if both:
        raise ValueError(f"set either a think share or a think threshold for a question type, not both: {both}")
    shares = {**config["share"], **given}
    tau = {}
    for q in TYPES:
        table = config["tau_table"][q]
        tau[q] = fixed[q] if q in fixed else table[round(float(shares[q]) * (len(table) - 1))]
    for q in fixed:
        shares[q] = None                                  # set by its threshold, not by a share
    out = {key: config[key] for key in ("budget", "opener", "suffix", "read", "mix", "temperatures")}
    out.update(tau=tau, share=shares, window=config["jevbench_limits"]["window"],
               warmup=config["jevbench_limits"]["warmup"])
    if budget is not None:
        if int(budget) < 1:
            raise ValueError("the think budget must be at least 1 token")
        out["budget"] = int(budget)
    for key in LIMITS:
        value = limits.get(key)
        default = config["jevbench_limits"].get(key, JEVBENCH_DEFAULTS.get(key)) if jevbench_limits else None
        out[key] = value if value is not None else default
    if out["decision_seconds"] is not None and float(out["decision_seconds"]) <= 0:
        raise ValueError("decision_seconds must be positive")
    out["read_partial"] = bool(config.get("read_partial", True) if read_partial is None else read_partial)
    return out


def base_weight(w, a, b, scale: float):
    """bf16(W - s B A): a base-model weight from a released (merged) one, in float32 as PEFT merges."""
    return (w.float() - scale * (b.float() @ a.float())).to(w.dtype)


def read_adapter(folder: Path) -> tuple[float, dict]:
    """(scale s, {module path: (A, B)}) of a released LoRA adapter (adapter/, PEFT format)."""
    from safetensors.torch import load_file
    folder = Path(folder)
    config = json.loads((folder / "adapter_config.json").read_text())
    if config.get("use_dora") or config.get("rank_pattern") or config.get("alpha_pattern") or config.get("lora_bias"):
        raise ValueError(f"{folder}: unsupported adapter options (DoRA, rank or alpha patterns, LoRA bias)")
    r, alpha = int(config["r"]), float(config["lora_alpha"])
    scale = alpha / math.sqrt(r) if config.get("use_rslora") else alpha / r
    tensors = load_file(str(folder / "adapter_model.safetensors"))
    names = sorted({k[: -len(".lora_A.weight")] for k in tensors if k.endswith(".lora_A.weight")})
    if not names or len(tensors) != 2 * len(names):
        raise ValueError(f"{folder}: expected one lora_A and one lora_B weight per adapted layer")
    return scale, {name.removeprefix("base_model.model."): (tensors[name + ".lora_A.weight"],
                                                           tensors[name + ".lora_B.weight"]) for name in names}


class LoraDelta:
    """The released LoRA adapter (adapter/, PEFT format) as forward hooks on the adapted linear layers. Inside base(),
    each adapted layer's output loses the adapter's term s B A x (computed in float32, as PEFT computes it), so a layer
    computes bf16(W + s B A) x - s B A x: the base model, up to one bfloat16 rounding of its weights. Outside base() the
    hooks change nothing: the released (merged) weights. No PEFT dependency.

    copy=True (--fast-reasoning): instead of hooks, a second copy of the adapted layers' weights, bf16(W - s B A), is
    swapped in inside base() (a pointer swap). Generation then runs at the speed of a plain model (about 1.5x faster on
    the 31B), at the cost of the adapted layers' memory once more; the base model is again exact up to bfloat16
    rounding, rounded once more than with the hooks."""

    def __init__(self, model, folder: Path, copy: bool = False):
        import torch
        self.scale, lora = read_adapter(folder)
        modules = dict(model.named_modules())
        device = next(model.parameters()).device
        self.active, self.handles, self.copies = False, [], []
        for path, (a, b) in lora.items():
            module = modules.get(path)
            if not isinstance(module, torch.nn.Linear):
                raise ValueError(f"{folder}: adapted layer {path} is not a linear layer of this model")
            a, b = a.float().to(device), b.float().to(device)
            if a.shape[1] != module.in_features or b.shape[0] != module.out_features or a.shape[0] != b.shape[1]:
                raise ValueError(f"{folder}: adapter shapes do not match layer {path}")
            if copy:
                with torch.no_grad():
                    self.copies.append((module, base_weight(module.weight, a, b, self.scale)))
            else:
                self.handles.append(module.register_forward_hook(self._hook(a, b)))
        self.layers = len(lora)

    def _hook(self, a, b):
        def hook(module, inputs, output):
            if not self.active:
                return None
            x = inputs[0]
            return output - (((x.to(a.dtype) @ a.T) @ b.T) * self.scale).to(output.dtype)
        return hook

    @contextlib.contextmanager
    def base(self):
        released = [m.weight.data for m, _ in self.copies]
        for m, w in self.copies:
            m.weight.data = w
        self.active = True
        try:
            yield
        finally:
            self.active = False
            for (m, _), w in zip(self.copies, released):
                m.weight.data = w

    @staticmethod
    def copy_fits(model, folder: Path, spare_bytes: int = 8 << 30) -> bool:
        """Whether the GPU has room for a second copy of the adapted layers (plus spare_bytes)."""
        import torch
        from safetensors import safe_open
        with safe_open(str(Path(folder) / "adapter_model.safetensors"), framework="pt") as f:
            names = {k[len("base_model.model."):-len(".lora_A.weight")] for k in f.keys() if k.endswith(".lora_A.weight")}
        modules = dict(model.named_modules())
        need = sum(modules[n].weight.numel() * modules[n].weight.element_size() for n in names if n in modules)
        device = next(model.parameters()).device
        return device.type != "cuda" or torch.cuda.mem_get_info(device)[0] > need + spare_bytes

def derive_base(folder: Path, cache: str | Path | None = None, device: str | None = None) -> Path:
    """A folder with the base model rebuilt from a release, for vLLM: the released (merged) weights minus the LoRA
    adapter (adapter/), each adapted weight bf16(W - s B A) as with --fast-reasoning, all other files as released.
    Written once under cache_dir(cache) (as large as the model's weights), then reused; no download of the original
    base model is needed."""
    import torch
    from safetensors.torch import load_file, save_file
    folder = Path(folder)
    index_file = folder / "model.safetensors.index.json"
    if index_file.is_file():                              # sharded checkpoint
        shards = sorted(set(json.loads(index_file.read_text())["weight_map"].values()))
    else:                                                 # one file
        shards = [f.name for f in sorted(folder.glob("model*.safetensors"))]
    if not shards:
        raise FileNotFoundError(f"{folder}: no model*.safetensors weights")
    digest = hashlib.sha256(json.dumps([[f, (folder / f).stat().st_size] for f in shards]).encode())
    if index_file.is_file():
        digest.update(index_file.read_bytes())
    digest.update((folder / "adapter" / "adapter_config.json").read_bytes())
    with open(folder / "adapter" / "adapter_model.safetensors", "rb") as f:
        for block in iter(lambda: f.read(1 << 24), b""):
            digest.update(block)
    name = json.loads((folder / "jeff_config.json").read_text()).get("name", folder.name)
    out = cache_dir(cache) / f"{name}-base-{digest.hexdigest()[:16]}"
    if (out / ".complete").is_file():
        return out
    need = sum((folder / shard).stat().st_size for shard in shards)
    out.parent.mkdir(parents=True, exist_ok=True)
    if shutil.disk_usage(out.parent).free < need * 1.05:
        raise OSError(f"rebuilding the base model for vLLM needs {need / 1e9:.0f} GB free in {out.parent}; set "
                      f"JEFF_CACHE (or --cache-dir) to a larger disk, or pass the original base model with --vllm-base")
    tmp = out.with_name(f"{out.name}.tmp{os.getpid()}")
    shutil.rmtree(tmp, ignore_errors=True)
    tmp.mkdir()
    device = device or ("cuda" if torch.cuda.is_available() else "cpu")
    scale, lora = read_adapter(folder / "adapter")
    done = set()
    started = time.perf_counter()
    for shard in shards:
        tensors = load_file(str(folder / shard))
        for key, w in tensors.items():
            path = key.removesuffix(".weight")
            if key.endswith(".weight") and path in lora:
                a, b = lora[path]
                tensors[key] = base_weight(w.to(device), a.to(device), b.to(device), scale).cpu()
                done.add(path)
        save_file(tensors, str(tmp / shard), metadata={"format": "pt"})
    missing = sorted(set(lora) - done)
    if missing:
        shutil.rmtree(tmp, ignore_errors=True)
        raise ValueError(f"{folder}: adapted layers without a weight in the checkpoint: {missing[:3]}")
    for file in VLLM_FILES:
        if (folder / file).is_file() and file != "config.json":
            shutil.copy2(folder / file, tmp / file)
    config = json.loads((folder / "config.json").read_text())
    arch = (config.get("architectures") or [""])[0]
    if arch in VLLM_ARCHITECTURES:
        config["architectures"], config["model_type"] = [VLLM_ARCHITECTURES[arch][0]], VLLM_ARCHITECTURES[arch][1]
    (tmp / "config.json").write_text(json.dumps(config, indent=2))
    (tmp / ".complete").write_text(json.dumps({"release": str(folder), "layers": len(done)}) + "\n")
    if device.startswith("cuda"):
        torch.cuda.empty_cache()                          # vLLM starts next and needs this memory free
    try:
        tmp.rename(out)
    except OSError:                                       # another process finished first
        shutil.rmtree(tmp, ignore_errors=True)
    print(f"rebuilt the base model for vLLM in {out} ({need / 1e9:.0f} GB, {time.perf_counter() - started:.0f} s)",
          flush=True)
    return out


class VLLMGenerator:
    """--reasoning-engine vllm: the base model in vLLM writes the reasoning (greedy, as the transformers path); the
    decision passes stay in this server. vLLM runs its engine in its own process on the same GPU. It must start before
    the decision model is loaded (it checks that its share of the GPU memory is free) and takes `memory` of the GPU's
    memory: the base model's weights, the KV cache and CUDA graphs for up to max_seqs sequences at once. `base` is a
    folder or repo id of the base model: by default the one rebuilt from the release (derive_base), or the original
    one (--vllm-base)."""

    def __init__(self, base: str, revision: str | None, tokenizer: str, max_len: int, memory: float, max_seqs: int = 1):
        try:
            from vllm import LLM
        except ImportError as e:
            raise ImportError("--reasoning-engine vllm needs vLLM: pip install \".[vllm]\" (vllm==0.30.0)") from e
        sizes = sorted({n for n in (1, 2, 4, 8, 16, 32, 64) if n <= max_seqs} | {max_seqs})
        # max_num_batched_tokens = one full-length prompt: vLLM then reserves the same working memory for several
        # sequences as for one, which leaves the KV cache of a full-length sequence in the same memory share
        kwargs = dict(model=base, revision=revision, tokenizer=tokenizer, dtype="bfloat16", max_model_len=max_len,
                      gpu_memory_utilization=memory, max_num_seqs=max_seqs, max_num_batched_tokens=max_len,
                      enable_prefix_caching=False, seed=0, compilation_config={"cudagraph_capture_sizes": sizes})
        try:
            self.llm = LLM(**kwargs, language_model_only=True)     # multimodal checkpoints: the text model only
        except (TypeError, ValueError):
            self.llm = LLM(**kwargs)

    def generate_many(self, prompts: list[list[int]], budget: int | list[int], stops: list[int]) -> list[list[int]]:
        """The written tokens for each prompt, in order (vLLM runs them as one batch); budget: one for all prompts, or
        one per prompt."""
        from vllm import SamplingParams
        from vllm.inputs import TokensPrompt
        budgets = budget if isinstance(budget, list) else [budget] * len(prompts)
        params = [SamplingParams(temperature=0.0, max_tokens=b, stop_token_ids=stops, detokenize=False,
                                 skip_special_tokens=False) for b in budgets]
        out = self.llm.generate([TokensPrompt(prompt_token_ids=p) for p in prompts], params, use_tqdm=False)
        return [list(o.outputs[0].token_ids) for o in out]

    def generate(self, ids: list[int], budget: int, stops: list[int]) -> list[int]:
        return self.generate_many([ids], budget, stops)[0]


def vllm_memory(folder: Path, spare_bytes: int = 12 << 30) -> float:
    """vLLM's share of the GPU memory: the base model's weights (as large as the released ones) plus spare_bytes for
    the KV cache of one full-length sequence (vLLM reserves it at start: 7.4 GB for the 31B), activations and the CUDA
    graphs. Raises ValueError if the GPU cannot hold the model twice."""
    import torch
    weights = sum(f.stat().st_size for f in Path(folder).glob("model*.safetensors"))
    total = torch.cuda.mem_get_info()[1]
    if 2 * weights + 2 * spare_bytes > total:
        raise ValueError(f"--reasoning-engine vllm needs the model twice on the GPU ({2 * weights / 1e9:.0f} GB of "
                         f"weights); this GPU has {total / 1e9:.0f} GB")
    return round((weights + spare_bytes) / total, 3)


def vllm_usable(folder: Path, device: str = "cuda") -> str | None:
    """Why --reasoning-engine auto cannot use vLLM here (None: it can)."""
    import importlib.util
    if not str(device).startswith("cuda"):
        return "not on a GPU"
    if importlib.util.find_spec("vllm") is None:
        return "vLLM is not installed (pip install \".[vllm]\")"
    try:
        vllm_memory(folder)
    except ValueError as error:
        return str(error)
    return None


def read_seconds(prefill: float, prompt_len: int, total_len: int) -> float:
    """Expected time of the read pass over total_len tokens, from the measured time of a forward pass (or prefill) over
    prompt_len tokens, with room to spare (x 1.5, + 50 ms)."""
    return 1.5 * prefill * total_len / max(1, prompt_len) + 0.05


class TimeLimit:
    """decision_seconds for one transformers generation (a stopping criterion): stop before the token after which the
    read would end later than `end` (a time.perf_counter() time). The read time is estimated from this generation's
    prefill (the time to its first token)."""

    def __init__(self, end: float, prompt_len: int, extra: int, clock=time.perf_counter):
        self.end, self.prompt_len, self.extra, self.clock = end, prompt_len, extra, clock
        self.start, self.first = clock(), None

    def __call__(self, input_ids, scores, **kwargs):
        import torch
        now = self.clock()
        new = input_ids.shape[1] - self.prompt_len
        if self.first is None:
            self.first = now - self.start
        step = (now - self.start - self.first) / (new - 1) if new > 1 else self.first
        stop = now + step + read_seconds(self.first, self.prompt_len, self.prompt_len + new + 1 + self.extra) > self.end
        return torch.full((input_ids.shape[0],), stop, dtype=torch.bool, device=input_ids.device)


class Reasoner:
    """Decides which questions reason (wants), writes and reads the reasoning (think, or its steps prompt, write,
    read_ids and read for batches), and keeps the counts the limits need. `decider` is the jeff.model.Decider it serves;
    `rule` the serving rule."""

    def __init__(self, decider, config: dict, delta: LoraDelta | None, rule: dict, static_cache: bool = False,
                 generator: VLLMGenerator | None = None):
        import torch
        from .prompting import LETTERS
        self.decider, self.config, self.delta, self.rule = decider, dict(config), delta, dict(rule or {})
        self.static_cache = static_cache          # --fast-reasoning: a static KV cache (with the weight copy)
        self.static_len = STATIC_PROMPT_TOKENS + int(self.config["budget"])     # its size (tokens)
        self.generator = generator                # --reasoning-engine vllm: the base model in vLLM writes
        tok, head = decider.tokenizer, decider.head
        self._torch = torch
        self._opener = tok.encode(self.config["opener"], add_special_tokens=False)
        self._suffix = tok.encode(self.config["suffix"], add_special_tokens=False)
        # the answer letters as the LM writes them after the suffix: bare (the head's letter rows) and with a space
        weight = decider.model.get_output_embeddings().weight
        spaced = []
        for letter in LETTERS[: head.k_slots]:
            ids = tok.encode(self.config["suffix"] + " " + letter, add_special_tokens=False)
            ok = len(ids) == len(self._suffix) + 1 and ids[: len(self._suffix)] == self._suffix
            spaced.append(ids[-1] if ok else None)
        self._spaced_ok = [i is not None for i in spaced]
        with torch.no_grad():
            self._spaced_rows = torch.stack([weight[i] if i is not None else torch.zeros_like(weight[0])
                                             for i in spaced]).float().to(decider.device)
        stops = set([tok.eos_token_id] if isinstance(tok.eos_token_id, int) else (tok.eos_token_id or []))
        for name in ("<end_of_turn>", "<turn|>", "<eos>"):
            if name in tok.get_vocab():
                stops.add(tok.convert_tokens_to_ids(name))
        self._stops = sorted(stops)
        self._pad = tok.pad_token_id if tok.pad_token_id is not None else self._stops[0]
        self._recent = collections.deque(maxlen=int(self.config["window"]))
        self.served = [0, 0]                    # questions answered and output tokens generated since the start
        self.pending = [0, 0]                   # questions still reasoning, and their budgets (counted as spent)
        self.deadline = None                    # time.perf_counter() after which no question of this request reasons
        self.started = time.perf_counter()      # when the current request arrived (decision_seconds counts from it)
        self._spt = 0.05                        # vLLM: seconds per generated token, as measured (for decision_seconds)

    def start_request(self) -> None:
        self.started = time.perf_counter()
        self.deadline = self.request_deadline()

    def decision_end(self, started: float | None = None) -> float | None:
        """The time.perf_counter() time by which a question of a request that arrived at `started` (default: the one
        start_request() saw) must be answered (decision_seconds; None: no limit)."""
        seconds = self.config.get("decision_seconds")
        if seconds is None:
            return None
        return (self.started if started is None else started) + float(seconds)

    def request_deadline(self) -> float | None:
        seconds = self.config.get("request_seconds")
        return time.perf_counter() + float(seconds) if seconds is not None else None

    def wants(self, qtype: str, probs: list[float], deadline: float | None | str = "request") -> bool:
        """Unsure (calibrated confidence below tau[type]) and the limits allow it. A question that reasons counts with
        its full budget until count() reports its real output. deadline: the question's request deadline (default:
        the one start_request() set)."""
        c = self.config
        deadline = self.deadline if deadline == "request" else deadline
        temp = float(self.rule.get(f"{qtype}_t", 1.0) or 1.0)
        logs = [math.log(max(p, 1e-12)) / temp for p in probs]
        top = max(logs)
        confidence = 1.0 / sum(math.exp(v - top) for v in logs)       # largest calibrated probability
        ok = confidence < float(c["tau"][qtype])
        if ok and deadline is not None and time.perf_counter() > deadline:
            ok = False                                    # this request took request_seconds: answer the rest at once
        if ok and c.get("max_share") is not None and len(self._recent) >= int(c["warmup"]) and self._recent:
            ok = sum(self._recent) / len(self._recent) < float(c["max_share"])
        if ok and c.get("max_output_per_decision") is not None:
            n, spent = self.served
            ok = ((spent + self.pending[1] + int(c["budget"])) / (n + self.pending[0] + 1)
                  <= float(c["max_output_per_decision"]))
        self._recent.append(1 if ok else 0)
        if ok:
            self.pending[0] += 1
            self.pending[1] += int(c["budget"])
        return ok

    def count(self, output_tokens: int, reasoned: bool = False) -> None:
        """A question is answered (reasoned: it was admitted by wants())."""
        self.served[0] += 1
        self.served[1] += int(output_tokens)
        if reasoned:
            self.pending[0] -= 1
            self.pending[1] -= int(self.config["budget"])

    def prompt(self, ids: list[int]) -> list[int]:
        return ids + self._opener

    def write(self, prompts: list[list[int]], ends: list[float | None] | None = None,
              t1s: list[float] | None = None) -> list[tuple[list[int], bool]]:
        """(reasoning, finished) for each prompt: the base model writes greedily up to the budget, cut before the first
        stop token; one vLLM batch, or one transformers generation after another. ends: per prompt, the time
        (time.perf_counter()) by which its read must be done (decision_end(); None: no limit); t1s: the seconds its
        question's one pass took (for the estimates). A reasoning that could not end by then, or not start, is not
        finished: the caller keeps the one-pass answer."""
        torch = self._torch
        from . import bidir
        budget, decider, extra = int(self.config["budget"]), self.decider, len(self._suffix)
        ends = ends or [None] * len(prompts)
        t1s = t1s or [0.0] * len(prompts)
        # the earliest a reasoning can be read: its prefill (about one pass) and the read of the prompt alone
        late = [e is not None and time.perf_counter() + t + read_seconds(t, len(p), len(p) + extra) > e
                for p, e, t in zip(prompts, ends, t1s)]
        caps = [budget] * len(prompts)
        outs = [None] * len(prompts)
        if self.generator is not None:
            now = time.perf_counter()
            for i, (p, e, t) in enumerate(zip(prompts, ends, t1s)):
                if e is not None and not late[i]:          # vLLM cannot stop on time: cap the tokens at its speed
                    room = e - now - t - read_seconds(t, len(p), len(p) + budget + extra)
                    caps[i] = max(0, min(budget, int(room / self._spt)))
            todo = [i for i in range(len(prompts)) if not late[i] and caps[i] > 0]
            if todo:
                start = time.perf_counter()
                got = self.generator.generate_many([prompts[i] for i in todo], [caps[i] for i in todo], self._stops)
                longest = max(len(g) for g in got)
                if longest:                                # a running estimate of the time per token
                    self._spt = 0.7 * self._spt + 0.3 * (time.perf_counter() - start) / longest
                for i, g in zip(todo, got):
                    outs[i] = g
        else:
            from transformers import StoppingCriteriaList
            for i, (prompt, end) in enumerate(zip(prompts, ends)):
                if late[i]:
                    continue
                x = torch.tensor([prompt], device=decider.device)
                stop = {} if end is None else {"stopping_criteria": StoppingCriteriaList([TimeLimit(end, len(prompt), extra)])}
                static = self.static_cache and len(prompt) + budget <= self.static_len
                with self.delta.base(), bidir.causal(decider.base):
                    out = decider.model.generate(input_ids=x, attention_mask=torch.ones_like(x), do_sample=False,
                                                 max_new_tokens=budget, eos_token_id=self._stops,
                                                 pad_token_id=self._pad, use_cache=True, **stop,
                                                 **({"cache_implementation": "static", "max_cache_len": self.static_len}
                                                    if static else {}))
                outs[i] = out[0, len(prompt):].tolist()
        result = []
        for written, end, prompt, t in zip(outs, ends, prompts, t1s):
            if written is None:
                result.append(([], False))
                continue
            gen, stopped = [], False
            for token in written:
                if token in self._stops:
                    stopped = True
                    break
                gen.append(token)
            # finished: ended by a stop token or the full budget (not by the time limit or a vLLM token cap)
            finished = stopped or len(gen) >= budget
            if finished and end is not None and self.generator is not None:
                finished = time.perf_counter() + read_seconds(t, len(prompt), len(prompt) + len(gen) + extra) <= end
            result.append((gen, finished))
        return result

    def can_read(self, prompt: list[int], gen: list[int], end: float | None, t1: float) -> bool:
        """Whether a reasoning cut by the time limit is read anyway (read_partial): it has tokens and its read still
        ends in time (the transformers time limit stops early enough for that; vLLM's token cap may not)."""
        return (bool(self.config.get("read_partial")) and bool(gen)
                and (end is None or time.perf_counter() + read_seconds(t1, len(prompt), len(prompt) + len(gen)
                                                                     + len(self._suffix)) <= end))

    def read_ids(self, prompt: list[int], gen: list[int]) -> list[int]:
        """What the decision model reads after the reasoning: prompt, reasoning, "Final answer:"."""
        return prompt + gen + self._suffix

    def read(self, h, k: int, qtype: str, first: list[float]) -> tuple[list[float], list[float]]:
        """(probabilities, logits) from the decision model's hidden state h [1, d] after read_ids; `first` = the
        one-pass option logits."""
        torch = self._torch
        c, head = self.config, self.decider.head
        h = h.float()
        if c.get("read", "letters") == "head":           # the trained head at the position after "Final answer:"
            z = head(h.to(torch.bfloat16).float())[0, :k]
        else:                                             # the LM's letter logits there, bare and spaced letters
            bare = head.cap(h @ head.base_rows.T)[0, :k]
            if all(self._spaced_ok[:k]):
                z = torch.logsumexp(torch.stack([bare, head.cap(h @ self._spaced_rows.T)[0, :k]]), dim=0)
            else:
                z = bare
        z = torch.log_softmax(z, dim=-1)
        if c.get("mix"):                                  # pooled with the one pass (mean of log-probabilities)
            z = (z + torch.log_softmax(torch.tensor(first, device=z.device, dtype=z.dtype), dim=-1)) / 2
        # The serving rule later divides the log-probabilities by its temperature for this type; scaling by
        # rule_t / think_t here makes the served distribution softmax(z / think_t), as fitted.
        think_t = float(c["temperatures"].get(qtype, 1.0))
        rule_t = float(self.rule.get(f"{qtype}_t", 1.0) or 1.0)
        logits = z * (rule_t / think_t)
        return torch.softmax(logits, dim=-1).tolist(), logits.tolist()

    def think(self, ids: list[int], k: int, qtype: str, first: list[float], end: float | None = None,
              t1: float = 0.0) -> tuple[list[float] | None, list[float] | None, int, bool]:
        """(probabilities, logits, generated tokens, read) after reasoning; `first` = the one-pass option logits;
        end, t1: as write(). A reasoning that did not finish in time is not read (None, None, its tokens, False), and
        the question keeps its one-pass answer, unless read_partial reads it as it stands (can_read)."""
        prompt = self.prompt(ids)
        gen, finished = self.write([prompt], [end], [t1])[0]
        if not finished and not self.can_read(prompt, gen, end, t1):
            return None, None, len(gen), False
        probs, logits = self.read(self.decider.hidden(self.read_ids(prompt, gen)), k, qtype, first)
        return probs, logits, len(gen), True

"""Serve a Jeff model over the TypeSafe "System One" wire format, as JevBench's stock `typesafe` adapter calls it.

    POST /v1/systemone  {"state": ..., "model": ..., "questions": {name: {type, instructions, criteria}}}
    -> {"answers": {name: answer}, "model": ..., "usage": {"input_tokens", "output_tokens"}, "runtime": {...}}
    GET  /             health check: {"status": "ok", "model": ...}

Answers: choice -> {"type": "choice", "choice": best option, "probabilities": {...}}; noul -> {"type": "noul",
"noul": P(yes)}; score -> {"type": "score", "score": best level, "probabilities": {...}}. Requests that arrive together
are answered in batches (jeff.batching; --batching off: one request at a time, its questions one after another).
Invalid requests get HTTP 422; a failure in the forward pass (e.g. out of GPU memory) gets HTTP 500. Both come with
{"error": message}. Yes/no answers between 0.2 and 0.8 are committed to 0.199 / 0.801 (--commit off: the calibrated
P(yes)).

By default every question is one forward pass (output_tokens 0). Inputs over the model's limit (8,192 tokens) keep
their question-relevant parts (--long-input refuse: HTTP 422 instead); questions with more than 16 options (up to
256) are answered in groups of 16.

Jeff 1.1 models can reason when unsure (jeff.reasoning): --reasoning on, with limits of your choice (--think-share,
--think-threshold, --max-think-share, --max-output-per-decision, --request-seconds, --decision-seconds) or the ones we
evaluate JevBench with (--jevbench-limits on):

    python -m jeff.serve jgeuter/Jeff-1.0-Large --host 0.0.0.0 --port 8013
    python -m jeff.serve jgeuter/Jeff-1.1-Large --reasoning on --jevbench-limits on --port 8013
"""
from __future__ import annotations

import argparse
import json
import time
import traceback
from http.server import BaseHTTPRequestHandler, HTTPServer, ThreadingHTTPServer
from pathlib import Path

from .model import JeffModel


def answer_serially(model: JeffModel, state, questions: dict) -> tuple[dict, int, int, float, int, int]:
    """(answers, input tokens, output tokens, forward seconds, questions that reasoned, reasonings dropped because
    they could not finish within decision_seconds), one question after another."""
    answers, tokens, forward, generated, thought, dropped = {}, 0, 0.0, 0, 0, 0
    model.decider.start_request()
    for key, question in questions.items():
        row = model.row(state, question, key)
        probs, _, n, seconds = model.decider.decide(row)
        answers[key] = model.answer(question["type"], [o["id"] for o in row["options"]], probs)
        tokens, forward = tokens + n, forward + seconds
        generated += int(model.decider.last.get("output_tokens", 0))
        thought += int(bool(model.decider.last.get("thought")))
        dropped += int(bool(model.decider.last.get("dropped")))
    return answers, tokens, generated, forward, thought, dropped


def answer_batched(batcher) -> callable:
    def answer(model: JeffModel, state, questions: dict) -> tuple[dict, int, int, float, int, int]:
        request = batcher.submit(state, questions)
        answers = {key: request.answers[key] for key in request.keys}
        return answers, request.tokens, request.generated, request.seconds, request.thought, request.dropped
    return answer


class BatchingServer(ThreadingHTTPServer):
    daemon_threads = True
    request_queue_size = 256


def make_handler(model: JeffModel, meta: dict, answer=answer_serially):
    class Handler(BaseHTTPRequestHandler):
        def log_message(self, *args):  # quiet
            pass

        def _send(self, status: int, body: dict):
            data = json.dumps(body).encode()
            self.send_response(status)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)

        def do_GET(self):
            self._send(200, {"status": "ok", "model": model.name})

        def do_POST(self):
            if self.path.rstrip("/") != "/v1/systemone":
                return self._send(404, {"error": "not found"})
            try:
                body = json.loads(self.rfile.read(int(self.headers.get("Content-Length", 0))))
                questions = body["questions"]
                if not isinstance(questions, dict) or not questions:
                    raise ValueError("questions must be a nonempty object")
                answers, tokens, generated, forward, thought, dropped = answer(model, body["state"], questions)
            except (KeyError, TypeError, ValueError) as error:
                return self._send(422, {"error": f"{type(error).__name__}: {error}"})
            except Exception as error:  # e.g. out of GPU memory: answer with the error instead of dropping the connection
                traceback.print_exc()
                return self._send(500, {"error": f"{type(error).__name__}: {error}"})
            self._send(200, {"answers": answers, "model": model.name,
                             "usage": {"input_tokens": tokens, "output_tokens": generated},
                             "runtime": {**meta, "forward_seconds": forward, "input_tokens": tokens,
                                         "reasoned": thought, "reasoning_dropped": dropped}})
    return Handler


def on_off(text: str) -> bool:
    if text not in ("on", "off"):
        raise argparse.ArgumentTypeError("expected on or off")
    return text == "on"


def think_share(text: str) -> float | dict:
    """0.3 (every type) or choice=0.2,noul=0.3,score=0.6 (the types not named keep their released setting)."""
    try:
        if "=" not in text:

"""JevBench / TypeSafe wire format <-> decision rows, and the serving rule.

- question_row(): a TypeSafe question (state + typed question with instructions and criteria) becomes one decision row,
  the way JevBench's own `semif_direct` adapter maps it: yes/no -> options "true", "false"; choice -> one option per
  criteria key, in request order; score -> options "0".."K-1"; every description is prefixed with "<id>: ";
- answer() turns the option distribution back into a TypeSafe answer object;
- apply_rule() is the serving rule: per-type temperatures, then yes/no answers with 0.2 < P(yes) < 0.8 moved to just
  outside the nearer edge (0.801 or 0.199), because JevBench counts answers inside that band as abstentions (wrong).
"""

from __future__ import annotations

import json
import math

NOUL_YES, NOUL_NO = 0.80, 0.20      # JevBench's yes/no band
BAND_YES, BAND_NO = 0.801, 0.199    # where a committed answer moves to


def _text(value) -> str:
    """An option description as text: strings as they are, structured values (objects, lists, numbers) as JSON."""
    return value if isinstance(value, str) else json.dumps(value, ensure_ascii=False)


def question_options(question: dict) -> list[dict]:
    """Options of one TypeSafe question, as JevBench's semif_direct adapter builds them (descriptions that are not
    strings, e.g. lists of colors or move objects, as JSON text)."""
    qtype, criteria = question["type"], question.get("criteria")
    if qtype == "noul":
        options = [{"id": key, "description": _text((criteria or {}).get(key, f"The proposition is {key}."))}
                   for key in ("true", "false")]
    elif qtype == "choice":
        if isinstance(criteria, dict):
            options = [{"id": key, "description": _text(value) if value not in (None, "", [], {}) else key}
                       for key, value in criteria.items()]
        else:  # a bare list of option ids
            options = [{"id": str(key), "description": str(key)} for key in criteria]
    elif qtype == "score":
        options = [{"id": str(i), "description": _text(level)} for i, level in enumerate(criteria)]
    else:
        raise ValueError(f"unknown question type {qtype!r}")
    return [{"id": o["id"], "description": o["id"] + ": " + o["description"]} for o in options]


def question_text(instructions) -> str:
    """The question's instructions as text: structured instructions (an object or array) as JSON, none as a note."""
    if isinstance(instructions, str) and instructions:
        return instructions
    if instructions is None or instructions == "" or instructions == {} or instructions == []:
        return "(no instructions were given)"
    return json.dumps(instructions, ensure_ascii=False)


def question_row(state, question: dict, row_id: str = "jevbench") -> dict:
    """One decision row (prompting.messages input) for a TypeSafe question."""
    return {"id": row_id, "state": state, "question": question_text(question["instructions"]),
            "options": question_options(question), "qtype": question["type"]}


def answer(qtype: str, option_ids: list[str], probabilities: list[float]) -> dict:
    """TypeSafe answer object from our distribution over the row's options."""
    probs = {i: float(p) for i, p in zip(option_ids, probabilities)}
    if qtype == "noul":
        return {"type": "noul", "noul": probs["true"]}
    best = max(option_ids, key=lambda i: probs[i])
    if qtype == "choice":
        return {"type": "choice", "choice": best, "probabilities": probs}
    return {"type": "score", "score": int(best), "probabilities": probs}


# ------------------------------------------------------------------ serving rule

def _logit(p: float) -> float:
    p = min(max(p, 1e-9), 1 - 1e-9)
    return math.log(p / (1 - p))


def noul_temperature(p: float, temp: float) -> float:
    return 1 / (1 + math.exp(-_logit(p) / temp))


def noul_edge(p: float, margin: float = 0.0) -> float:
    """Inside the abstention band and at least `margin` from 0.5: move to the band edge."""
    if NOUL_NO < p < NOUL_YES and abs(p - 0.5) >= margin and p != 0.5:
        return BAND_YES if p > 0.5 else BAND_NO
    return p


def score_temperature(probs: list[float], temp: float) -> list[float]:
    logs = [math.log(max(p, 1e-12)) / temp for p in probs]
    top = max(logs)
    exp = [math.exp(v - top) for v in logs]
    total = sum(exp)
    return [v / total for v in exp]


def apply_rule(qtype: str, probs: dict, rule: dict) -> dict:
    """rule: {"noul_t": T, "noul_edge": margin or None, "score_t": T, "choice_t": T} (missing = identity).
    noul probs {"yes", "no"}; score probs {"0": ..}; choice probs {label: p}."""
    if qtype == "choice" and rule.get("choice_t", 1.0) != 1.0:
        keys = list(probs)
        return dict(zip(keys, score_temperature([probs[k] for k in keys], rule["choice_t"])))
    if qtype == "noul":
        p = probs["yes"]
        if rule.get("noul_t", 1.0) != 1.0:
            p = noul_temperature(p, rule["noul_t"])
        if rule.get("noul_edge") is not None:
            p = noul_edge(p, rule["noul_edge"])
        return {"yes": p, "no": 1.0 - p}
    if qtype == "score" and rule.get("score_t", 1.0) != 1.0:
        keys = sorted(probs, key=int)
        return dict(zip(keys, score_temperature([probs[k] for k in keys], rule["score_t"])))
    return probs

"""Tiny random Jeff release folders (CPU, no downloads): a Gemma 4 or Qwen3.5 text model with a few layers, a

import pytest
import torch

RULE = {"choice_t": 1.3, "noul_t": 1.2, "score_t": 1.1, "noul_edge": 0.0}
TARGETS = {"gemma": ["q_proj", "v_proj", "gate_proj", "down_proj"],

SPECIAL = ["<pad>", "<eos>", "<unk>", "<turn|>"]

def char_tokenizer():
    from tokenizers import Tokenizer, decoders, models
    from transformers import PreTrainedTokenizerFast
    chars = [chr(i) for i in range(32, 127)] + ["\n", "ü", "€"]
    vocab = {tok: i for i, tok in enumerate(SPECIAL + chars)}
    core = Tokenizer(models.BPE(vocab=vocab, merges=[], unk_token="<unk>"))
    core.decoder = decoders.Fuse()
    tok = PreTrainedTokenizerFast(tokenizer_object=core, eos_token="<eos>", pad_token="<pad>", unk_token="<unk>",
                                  additional_special_tokens=["<turn|>"])
    tok.chat_template = TEMPLATE
    return tok


def tiny_config(kind: str, vocab: int):
    import transformers
    common = dict(vocab_size=vocab, hidden_size=64, intermediate_size=128, num_hidden_layers=4, num_attention_heads=4,
                  num_key_value_heads=2, head_dim=16, max_position_embeddings=8192, eos_token_id=1, pad_token_id=0,
                  bos_token_id=None)
    if kind == "gemma":
        return transformers.AutoConfig.for_model(
            "gemma4_text", global_head_dim=32, sliding_window=8, final_logit_softcapping=30.0,

    return transformers.AutoConfig.for_model(

def build(folder, kind: str = "gemma", bidirectional: str | None = None, reasoning: bool = True,
          max_input_tokens: int = 8192, seed: int = 0) -> dict:
    """Write a release folder; returns {"base": the base model (bfloat16), "lora": {layer: (A, B)}, "scale": s}."""
    import transformers
    from safetensors.torch import save_file
    tok = char_tokenizer()
    torch.manual_seed(seed)
    base = transformers.AutoModelForCausalLM.from_config(tiny_config(kind, len(tok))).to(torch.bfloat16).eval()
    merged = transformers.AutoModelForCausalLM.from_config(tiny_config(kind, len(tok))).to(torch.bfloat16).eval()
    merged.load_state_dict(base.state_dict())
    r, alpha = 4, 8
    scale, lora, tensors = alpha / r, {}, {}
    modules = dict(merged.named_modules())
    for name, module in base.named_modules():
        if isinstance(module, torch.nn.Linear) and name.split(".")[-1] in TARGETS[kind]:
            a = torch.randn(r, module.in_features) * 0.05      # s B A about half the size of W, as in training
            b = torch.randn(module.out_features, r) * 0.05
            lora[name] = (a, b)
            tensors[f"base_model.model.{name}.lora_A.weight"] = a.contiguous()
            tensors[f"base_model.model.{name}.lora_B.weight"] = b.contiguous()
            with torch.no_grad():                         # as PEFT merges: bf16(W + s B A)
                w = modules[name].weight
                w.copy_((w.float() + scale * (b @ a)).to(w.dtype))
    folder.mkdir(parents=True, exist_ok=True)
    merged.save_pretrained(folder)
    tok.save_pretrained(folder)
    (folder / "adapter").mkdir()
    save_file(tensors, str(folder / "adapter" / "adapter_model.safetensors"))
    (folder / "adapter" / "adapter_config.json").write_text(json.dumps(
        {"peft_type": "LORA", "r": r, "lora_alpha": alpha, "target_modules": TARGETS[kind], "use_rslora": False}))
    letters = [tok.convert_tokens_to_ids(c) for c in "ABCDEFGHIJKLMNOP"]
    rows = merged.get_output_embeddings().weight.detach()[letters].float()
    d = rows.shape[1]
    torch.manual_seed(seed + 1)
    save_file({"base_rows": rows.contiguous(), "delta.weight": torch.randn(16, d) * 0.05, "delta.bias": torch.zeros(16),

    softcap = merged.config.final_logit_softcapping if kind == "gemma" else None
    (folder / "head_config.json").write_text(json.dumps({"kind": "residual", "d_model": d, "k_slots": 16,
                                                         "softcap": softcap}))
    (folder / "serving_rule.json").write_text(json.dumps(RULE))
    config = {"name": f"tiny-{kind}", "prompt_version": "direct-options-v1", "noul_mapping": "tf-true-first",

    if reasoning:
        # thresholds 0.3 .. 0.99 for shares 0.01 .. 0.99; share 0: never (-1), share 1: always (2)
        table = [-1.0] + [0.3 + 0.69 * i / 99 for i in range(1, 100)] + [2.0]

    return {"base": base, "lora": lora, "scale": scale}

"""1.3 serving on tiny random models (CPU, see conftest.py): batched forward passes, the batching server, reasoning in
batches and its limits under concurrency, thresholds and the hard share cap, and the base model rebuilt for vLLM."""
import json
import shutil

import time
import urllib.request
from collections import namedtuple

import pytest
import torch

from jeff import reasoning as R
from jeff.batching import Batcher
from jeff.model import JeffModel
from jeff.serve import BatchingServer, answer_batched, make_handler

STATE = {"ticket": "Refund not received after 14 days", "customer": "J. Doe"}
REQUEST = {"route": {"type": "choice", "instructions": "Which team should handle this?",
                     "criteria": {"billing": "Payments and refunds", "tech": "Technical problems", "sales": "Orders"}},
           "urgent": {"type": "noul", "instructions": "Is this urgent?"},
           "severity": {"type": "score", "instructions": "How severe is it?", "criteria": ["low", "mid", "high"]}}
STATES = [STATE, {"ticket": "App crashes when I upload a photo"}, "Please cancel order 4411 before it ships.",
          {"note": "x" * 300}, {"ticket": "Where is my parcel?", "days": 9}, "Charged twice."]


def load(folder, **options) -> JeffModel:
    return JeffModel(folder, device="cpu", **options)


def serial(model, state) -> dict:
    return model.decide(state, REQUEST)


def concurrently(batcher, states) -> list:
    out = [None] * len(states)

    def run(i):
        out[i] = batcher.submit(states[i], REQUEST)
    threads = [threading.Thread(target=run, args=(i,)) for i in range(len(states))]
    for t in threads:
        t.start()
    for t in threads:
        t.join(60)
    return out


def close(a: dict, b: dict, tol: float = 0.03) -> bool:
    for key in a:
        x, y = a[key], b[key]
        if "probabilities" in x:
            if any(abs(x["probabilities"][o] - y["probabilities"][o]) > tol for o in x["probabilities"]):
                return False
        elif abs(x["noul"] - y["noul"]) > tol:
            return False
    return True


@pytest.mark.parametrize("kind,bidirectional", [("gemma", None), ("gemma", "full"), ("qwen", None), ("qwen", "full")])
def test_batched_forward_pass_matches_single_ones(tiny, kind, bidirectional):
    folder, _ = tiny(kind, bidirectional)
    model = load(folder)
    rows = [model.decider.prepare(model.row(s, REQUEST["urgent"]))[1] for s in STATES]
    assert len({len(ids) for ids in rows}) > 1                      # different lengths: padding is exercised
    with torch.no_grad():
        alone = model.decider.hidden_batch(rows[:1])
        assert torch.equal(alone, model.decider.hidden(rows[0]))    # one input: exactly the single pass
        model.decider.model.float()                                 # in float32 the batch gives the same states
        single = torch.cat([model.decider.hidden(ids) for ids in rows])
        batched = model.decider.hidden_batch(rows)
    assert (batched - single).abs().max() / single.abs().mean() < 1e-4


def test_batcher_answers_like_serial_serving(tiny):
    folder, _ = tiny("gemma", "full")
    model = load(folder)
    expected = [serial(model, s) for s in STATES]
    batcher = Batcher(model, max_batch=8)
    sizes = []
    hidden_batch = model.decider.hidden_batch
    model.decider.hidden_batch = lambda batch: (sizes.append(len(batch)), hidden_batch(batch))[1]
    got = concurrently(batcher, STATES)
    for request, answers in zip(got, expected):
        assert set(request.answers) == set(REQUEST) and request.left == 0 and request.thought == 0
        assert close(request.answers, answers)

"""The decision head: its formula and the release format."""
import json

import pytest
import torch
from safetensors.torch import save_file

from jeff.head import DecisionHead, load_head

D = 8


def random_head(softcap=None) -> DecisionHead:
    torch.manual_seed(0)
    head = DecisionHead(D, softcap=softcap)
    with torch.no_grad():
        head.base_rows.normal_()
        head.delta.weight.normal_()
        head.delta.bias.normal_()
        head.mu.normal_()
        head.sigma.uniform_(0.5, 2.0)
    return head


@pytest.mark.parametrize("softcap", [None, 30.0, 2.0])
def test_formula(softcap):
    head, h = random_head(softcap), torch.randn(3, D)
    readout = h @ head.base_rows.T
    if softcap:
        readout = softcap * torch.tanh(readout / softcap)
    correction = ((h - head.mu) / head.sigma) @ head.delta.weight.T + head.delta.bias
    torch.testing.assert_close(head(h), readout + correction)


def test_zero_correction_is_the_letter_readout():
    head, h = DecisionHead(D), torch.randn(2, D)
    with torch.no_grad():
        head.base_rows.normal_()
        head.delta.weight.zero_()
        head.delta.bias.zero_()
    torch.testing.assert_close(head(h), h @ head.base_rows.T)


def save_release(folder, head: DecisionHead, config: dict | None = None, drop: set = frozenset()) -> None:
    """head_config.json + head.safetensors as in the released models, including the unused abstain unit."""
    config = {"d_model": D, "k_slots": 16, "abstain": True, "kind": "residual", "extra_dim": 0, "extra_layers": [],
              "logit_stats": False, "t_min": 0.05, **({"softcap": head.softcap} if head.softcap else {}), **(config or {})}
    (folder / "head_config.json").write_text(json.dumps(config))
    tensors = {k: v.contiguous() for k, v in head.state_dict().items() if k not in drop}
    tensors.update({"abstain_net.weight": torch.zeros(1, D), "abstain_net.bias": torch.full((1,), -3.0)})
    save_file(tensors, str(folder / "head.safetensors"))


def test_load_release_format(tmp_path):
    head = random_head(30.0)
    save_release(tmp_path, head)
    loaded, h = load_head(tmp_path), torch.randn(2, D)
    assert loaded.softcap == 30.0
    torch.testing.assert_close(loaded(h), head(h), rtol=0, atol=0)


def test_missing_tensor_is_an_error(tmp_path):
    save_release(tmp_path, random_head(), drop={"mu"})
    with pytest.raises(RuntimeError, match="mu"):
        load_head(tmp_path)


@pytest.mark.parametrize("change", [{"kind": "linear"}, {"kind": "temperature"}, {"extra_dim": 4}, {"k_slots": 8}])
def test_other_heads_are_refused(tmp_path, change):
    save_release(tmp_path, random_head(), change)
    with pytest.raises(ValueError, match="unsupported"):
        load_head(tmp_path)

"""The long-input filter (jeff.longinput): what is kept, in which order, and that the result fits."""
import json

class WordTokenizer:
    def encode(self, text, add_special_tokens=False):
        return text.split()

    def decode(self, ids):
        return " ".join(ids)


RENDER = lambda tok, r: (r["state"] if isinstance(r["state"], str) else json.dumps(r["state"])) + " " + r["question"]  # noqa: E731


def test_shorten_lines_keeps_the_question_lines_in_order():
    lines = ["SUPPORT LOG header: the owner is set by the most recent assignment",
             "2026-01-01 | SUP-1 | assigned to A"] + [f"2026-01-{i % 28 + 1:02d} | SUP-{1000 + i} | note" for i in range(3000)]
    lines.insert(1700, "2026-05-05 | SUP-605069 | reassigned to Bo")
    lines.insert(400, "2026-02-02 | SUP-605069 | created, assigned to Al")
    row = {"id": "x", "state": "\n".join(lines), "question": "Who owns ticket SUP-605069 at the end of the log?"}
    render = lambda tok, r: r["state"] + " " + r["question"]          # noqa: E731
    out = longinput.shorten(WordTokenizer(), row, 400, render)[0]
    kept = out["state"].split("\n")
    assert kept[0] == lines[0]
    assert [x for x in kept if "SUP-605069 |" in x] == ["2026-02-02 | SUP-605069 | created, assigned to Al",
                                                         "2026-05-05 | SUP-605069 | reassigned to Bo"]
    assert len(render(None, out).split()) <= 400

"""The prompt: SemIf's format, row checks and the input limit."""
import json

import pytest

from jeff.prompting import DIRECT_SYSTEM, LETTERS, encode_prompt, messages, render_prompt, validate_row

ROW = {"id": "route", "state": {"ticket": "Refund not received"}, "question": "Which team should handle this?",
       "options": [{"id": "billing", "description": "billing: Payments"}, {"id": "tech", "description": "tech: Bugs"}]}


def changed(**change) -> dict:
    return {**ROW, **change}


def options(n: int) -> list[dict]:
    return [{"id": f"o{i}", "description": f"o{i}: option {i}"} for i in range(n)]


def test_semif_messages():
    system, user = messages(ROW)
    assert system == {"role": "system", "content": DIRECT_SYSTEM}
    assert user == {"role": "user", "content":
                    '{"evidence": {"ticket": "Refund not received"}, "criterion": "Which team should handle this?", '
                    '"options": [{"letter": "A", "description": "billing: Payments"}, '
                    '{"letter": "B", "description": "tech: Bugs"}]}'}


def test_text_is_not_escaped():
    _, user = messages(changed(state="Rückerstattung über 50 €"))
    assert "Rückerstattung über 50 €" in user["content"]


def test_sixteen_options_get_letters_a_to_p():
    payload = json.loads(messages(changed(options=options(16)))[1]["content"])
    assert [o["letter"] for o in payload["options"]] == list(LETTERS)


@pytest.mark.parametrize("change", [
    {"options": options(1)}, {"options": options(17)}, {"options": [ROW["options"][0]] * 2},
    {"options": [{"id": "a"}, {"id": "b"}]}, {"state": ""}, {"state": {"x": float("nan")}}, {"question": ""},
])
def test_invalid_rows_are_refused(change):
    with pytest.raises(ValueError):
        validate_row(changed(**change))


def test_missing_field_is_refused():
    with pytest.raises(ValueError, match="missing"):
        validate_row({k: v for k, v in ROW.items() if k != "state"})


class FakeTokenizer:
    """Records the chat-template arguments; one token per character."""

    def apply_chat_template(self, messages, **kwargs):
        self.kwargs = kwargs
        return "".join(m["content"] for m in messages)

    def encode(self, text, add_special_tokens):
        assert add_special_tokens is False
        return [ord(c) for c in text]


def test_chat_template_without_thinking():
    tokenizer = FakeTokenizer()
    assert render_prompt(tokenizer, ROW).startswith(DIRECT_SYSTEM)
    assert tokenizer.kwargs == {"tokenize": False, "add_generation_prompt": True, "enable_thinking": False}


def test_long_inputs_are_refused_not_truncated():
    tokenizer = FakeTokenizer()
    n = len(encode_prompt(tokenizer, ROW, max_tokens=10_000))
    assert len(encode_prompt(tokenizer, ROW, max_tokens=n)) == n
    with pytest.raises(ValueError, match="exceed limit"):
        encode_prompt(tokenizer, ROW, max_tokens=n - 1)

"""Jeff 1.1 serving on tiny random models (CPU, see conftest.py): the base model behind the adapter, bidirectional
attention, reasoning when unsure and its limits, questions with many options and long inputs; Jeff 1.0 folders keep
their one-pass answers."""

STATE = {"ticket": "Refund not received after 14 days", "customer": "J. Doe"}
REQUEST = {"route": {"type": "choice", "instructions": "Which team should handle this?",
                     "criteria": {"billing": "Payments and refunds", "tech": "Technical problems", "sales": "Orders"}},
           "urgent": {"type": "noul", "instructions": "Is this urgent?"},
           "severity": {"type": "score", "instructions": "How severe is it?", "criteria": ["low", "mid", "high"]}}


def load(folder, **options) -> JeffModel:
    return JeffModel(folder, device="cpu", **options)


def one_pass(model: JeffModel, row: dict) -> list[float]:
    """The one-pass answer computed by hand: hidden state at the last prompt token -> head -> softmax."""
    ids = encode_prompt(model.decider.tokenizer, row, model.decider.max_tokens)
    with torch.no_grad():
        h = model.decider.hidden(ids).to(torch.bfloat16).float()
        return torch.softmax(model.decider.head(h)[0, : len(row["options"])], dim=-1).tolist()


def test_one_pass_is_unchanged_and_reasoning_is_off_by_default(tiny):
    folder, _ = tiny("gemma")
    model = load(folder)
    assert model.decider.reasoner is None and model.reasoning is None and model.decider.bidirectional is None
    for key, question in REQUEST.items():
        row = model.row(STATE, question, key)
        probs, _, n, _ = model.decider.decide(row)
        assert probs == pytest.approx(one_pass(model, row), abs=1e-6) and n > 0
        assert model.decider.last == {"output_tokens": 0, "thought": False, "dropped": False, "shortened": False}

@pytest.mark.parametrize("kind", ["gemma", "qwen"])
def test_adapter_hooks_give_back_the_base_model(tiny, kind):
    """Released weights bf16(W + s B A) minus the adapter's term: each adapted layer is the base layer up to bfloat16
    rounding, and the whole model is much closer to the base model than the released one is."""
    folder, info = tiny(kind)
    model = load(folder, reasoning=True)
    delta = model.decider.reasoner.delta
    assert delta.layers == len(info["lora"]) and delta.scale == info["scale"]
    released, base = dict(model.decider.model.named_modules()), dict(info["base"].named_modules())
    torch.manual_seed(0)
    for name in list(info["lora"])[:6]:
        x = torch.randn(3, base[name].in_features, dtype=torch.bfloat16)
        with torch.no_grad(), delta.base():
            off = released[name](x).float()
        on = released[name](x).float()
        want = base[name](x).float()
        assert torch.allclose(off, want, atol=0.05, rtol=0.02)
        assert (on - want).abs().max() > 10 * (off - want).abs().max()
    ids = torch.randint(10, 90, (1, 24))
    with torch.no_grad():
        on = model.decider.model(ids).logits.float()
        with delta.base():
            off = model.decider.model(ids).logits.float()
        want = info["base"](ids).logits.float()
    assert (off - want).norm() < 0.2 * (on - want).norm()
    assert not delta.active


def test_bidirectional_models_read_both_ways_and_reason_causally(tiny):
    causal, _ = tiny("gemma")
    folder, _ = tiny("gemma", "full")                     # the same weights (same seed)
    a, b = load(causal), load(folder, reasoning=True, think_share=1.0)
    assert b.decider.bidirectional == "full"
    full = [layer for layer in b.decider.base.layers if layer.self_attn.is_causal is False]
    assert len(full) == 2                                 # the full-attention layers; sliding layers stay causal
    row = a.row(STATE, REQUEST["route"], "route")
    assert one_pass(a, row) != pytest.approx(one_pass(b, row), abs=1e-4)
    b.decider.decide(row)
    assert b.decider.last["thought"]
    assert all(layer.self_attn.is_causal is False for layer in full)      # restored after generating causally

def test_reasoned_answer_is_the_pooled_read_at_its_temperature(tiny):
    """The served distribution is softmax(z / think_t) with z the mean of the one-pass and read log-probabilities."""
    folder, _ = tiny("gemma")
    model = load(folder, reasoning=True, think_share=1.0)
    reasoner = model.decider.reasoner
    row = model.row(STATE, REQUEST["route"], "route")
    ids = encode_prompt(model.decider.tokenizer, row, 8192)
    first = one_pass(model, row)
    with torch.no_grad():
        probs, logits, _, finished = reasoner.think(ids, 3, "choice", [float(v) for v in torch.tensor(first).log()])
    assert finished
    reasoner.config["mix"] = False
    with torch.no_grad():
        read, _, _, _ = reasoner.think(ids, 3, "choice", [0.0, 0.0, 0.0])     # read alone (pooling off)
    think_t, rule_t = reasoner.config["temperatures"]["choice"], model.rule["choice_t"]
    z = (torch.tensor(read).log() * think_t / rule_t + torch.tensor(first).log()) / 2   # undo the scaling of `read`
    want = torch.softmax(z / think_t, dim=-1)
    served = model.answer("choice", ["billing", "tech", "sales"], probs)["probabilities"]
    assert list(served.values()) == pytest.approx(want.tolist(), abs=1e-5)

def test_time_limit_stops_before_the_token_that_would_end_too_late():
    """TimeLimit (decision_seconds) on a fake clock: the prefill (time to the first token) gives the read estimate,
    the steps so far the time per token; it stops once the next token and the read would end after `end`."""
    now = [100.0]
    limit = R.TimeLimit(end=104.0, prompt_len=100, extra=4, clock=lambda: now[0])
    ids = lambda n: torch.zeros((1, 100 + n), dtype=torch.long)
    now[0] = 100.5            # prefill and first token 0.5 s; next token 0.5 s, read 1.5 x 0.5 x 106 / 100 + 0.05 s
    assert not limit(ids(1), None).item()
    now[0] = 101.0            # 0.5 s per token
    assert not limit(ids(2), None).item()
    now[0] = 102.7            # slower: 1.1 s per token, 102.7 + 1.1 + 0.86 > 104
    assert limit(ids(3), None).item()

def test_a_reasoning_cut_by_the_time_limit_is_dropped(tiny, monkeypatch):
    """read_partial off: a generation the time limit stops is not read: the one-pass answer, with the written tokens
    counted."""
    folder, _ = tiny("gemma")
    model = load(folder, reasoning=True, think_share=1.0, decision_seconds=600.0, read_partial=False)
    reasoner = model.decider.reasoner
    ids = encode_prompt(model.decider.tokenizer, model.row(STATE, REQUEST["route"], "route"), 8192)
    with torch.no_grad():
        full, finished = reasoner.write([reasoner.prompt(ids)])[0]
    assert finished
    if len(full) < 2:
        pytest.skip("the tiny model stops at once")

    class OutOfTime(R.TimeLimit):                       # no time after the first token
        def __call__(self, input_ids, scores, **kwargs):
            return torch.ones(input_ids.shape[0], dtype=torch.bool)

    monkeypatch.setattr(R, "TimeLimit", OutOfTime)
    with torch.no_grad():
        gen, finished = reasoner.write([reasoner.prompt(ids)], [reasoner.decision_end()], [0.0])[0]
        assert not finished and gen == full[:1]
        assert reasoner.think(ids, 3, "choice", [0.0, 0.0, 0.0], reasoner.decision_end(), 0.0) == (None, None, 1, False)
    plain = load(folder)
    assert model.decide(STATE, {"route": REQUEST["route"]}) == plain.decide(STATE, {"route": REQUEST["route"]})
    assert model.decider.last["dropped"] and model.decider.last["output_tokens"] == 1
    assert reasoner.served == [1, 1]

def test_many_options_are_answered_in_groups(tiny):
    folder, _ = tiny("gemma")
    model = load(folder, reasoning=True, think_share=1.0)
    options = {f"o{i}": f"Option number {i}" for i in range(40)}
    answer = model.decide(STATE, {"wide": {"type": "choice", "instructions": "Which fits?", "criteria": options}})["wide"]
    assert len(answer["probabilities"]) == 40 and answer["choice"] in options
    assert sum(answer["probabilities"].values()) == pytest.approx(1.0, abs=1e-5)
    assert model.decider.last["groups"] == 3 and not model.decider.last["thought"]   # wide questions do not reason
    for n in range(17, 257):                               # consecutive, at most 16, sizes differ by at most 1
        groups = split_groups(n, 16)
        sizes = [len(g) for g in groups]
        assert sum(groups, []) == list(range(n)) and max(sizes) <= 16 and max(sizes) - min(sizes) <= 1 and min(sizes) >= 2
        assert len(groups) <= 16
    assert model.decider.reasoner is not None
    for n in (17, 33, 256):                               # no group may be left with a single option
        options = {f"o{i}": f"Option number {i}" for i in range(n)}
        answer = model.decide(STATE, {"w": {"type": "choice", "instructions": "Which fits?", "criteria": options}})["w"]
        assert len(answer["probabilities"]) == n and sum(answer["probabilities"].values()) == pytest.approx(1.0, abs=1e-5)
    levels = [f"level {i}" for i in range(20)]
    answer = model.decide(STATE, {"s": {"type": "score", "instructions": "How much?", "criteria": levels}})["s"]
    assert 0 <= answer["score"] < 20
    too_many = {f"o{i}": "x" for i in range(257)}
    with pytest.raises(ValueError, match="2-256"):
        model.decide(STATE, {"wide": {"type": "choice", "instructions": "Which?", "criteria": too_many}})


def test_long_and_empty_inputs_are_filtered_or_refused(tiny):
    folder, _ = tiny("gemma", max_input_tokens=900)
    lines = ["LOG: the owner is the last assignee"] + [f"2026-01-{i % 28 + 1:02d} SUP-{1000 + i} note" for i in range(200)]

    wide = {"type": "choice", "instructions": "Which code?", "criteria": {f"c{i}": f"code {i}" for i in range(20)}}
    for empty in ("", {}, []):                       # refuse mode still sends empty states as text (since 1.3)
        assert strict.decide(empty, {"q": question})["q"]["choice"] in ("bo", "al")
        assert strict.decide(empty, {"w": wide})["w"]["choice"] in wide["criteria"]     # also with > 16 options

    try:
        request = urllib.request.Request(f"http://127.0.0.1:{httpd.server_address[1]}/v1/systemone",
                                         data=json.dumps({"state": STATE, "questions": REQUEST}).encode())

    assert body["runtime"]["reasoned"] == 3 and body["runtime"]["reasoning_dropped"] == 0
    assert body["usage"]["output_tokens"] == model.decider.reasoner.served[1] and body["usage"]["input_tokens"] > 0

def test_compiled_forward_gives_the_same_answers(tiny, monkeypatch):

def test_fast_reasoning_swaps_in_a_copy_of_the_base_weights(tiny, kind):
    """--fast-reasoning: inside base() the adapted layers hold bf16(W_released - s B A) (close to the base layers),
    outside it the released weights again; generation uses a static KV cache; the answers are still distributions."""

    model = load(folder, reasoning=True, think_share=1.0, fast_reasoning=True)
    reasoner = model.decider.reasoner
    assert model.fast_reasoning and reasoner.static_cache and not reasoner.delta.handles

    with torch.no_grad(), reasoner.delta.base():
        off = released[name](x).float()
    assert released[name].weight.data_ptr() == before
    assert torch.allclose(off, base[name](x).float(), atol=0.05, rtol=0.02)
    answer = model.decide(STATE, {"route": REQUEST["route"]})["route"]
    assert model.decider.last["thought"] and sum(answer["probabilities"].values()) == pytest.approx(1.0, abs=1e-6)


def test_shared_fast_reasoning_compiles_the_hooks_without_a_copy(tiny):

def test_fast_reasoning_uses_one_static_cache_size(tiny, monkeypatch):
    """--fast-reasoning: every reasoning uses one static cache size (compiled once, at warm-up); a prompt too long for
    it reasons with a dynamic cache (not compiled), and writes the same reasoning."""
    folder, _ = tiny("gemma")
    model = load(folder, reasoning=True, think_share=1.0, fast_reasoning="shared")
    r, budget = model.decider.reasoner, int(model.reasoning["budget"])
    assert r.static_len == R.STATIC_PROMPT_TOKENS + budget
    seen, real = [], model.decider.model.generate
    monkeypatch.setattr(model.decider.model, "generate",
                        lambda **kw: seen.append((kw.get("cache_implementation"), kw.get("max_cache_len"))) or real(**kw))
    prompt = r.prompt(encode_prompt(model.decider.tokenizer, model.row(STATE, REQUEST["route"], "route"), 8192))
    with torch.no_grad():
        short = r.write([prompt])
        r.static_len = len(prompt) + budget - 1          # one token too long for the static cache
        long = r.write([prompt])
    assert seen == [("static", R.STATIC_PROMPT_TOKENS + budget), (None, None)]
    assert short == long


def test_read_partial_reads_a_reasoning_the_time_limit_cut(tiny, monkeypatch):
    """read_partial (the default): a reasoning stopped by the time limit is read as it stands (prompt, its tokens,
    "Final answer:"), not dropped; without tokens there is nothing to read and the one pass stays. A reasoning config
    can turn it off, and the option overrides the config."""
    folder, _ = tiny("gemma")
    model = load(folder, reasoning=True, think_share=1.0, decision_seconds=600.0)
    reasoner = model.decider.reasoner
    assert model.reasoning["read_partial"] is True
    assert load(folder, reasoning=True, reasoning_config={"read_partial": False}).reasoning["read_partial"] is False
    assert load(folder, reasoning=True, reasoning_config={"read_partial": False},
                read_partial=True).reasoning["read_partial"] is True
    ids = encode_prompt(model.decider.tokenizer, model.row(STATE, REQUEST["route"], "route"), 8192)
    with torch.no_grad():
        full, _ = reasoner.write([reasoner.prompt(ids)])[0]
    if len(full) < 2:
        pytest.skip("the tiny model stops at once")

    class OutOfTime(R.TimeLimit):                       # no time after the first token
        def __call__(self, input_ids, scores, **kwargs):
            return torch.ones(input_ids.shape[0], dtype=torch.bool)

    monkeypatch.setattr(R, "TimeLimit", OutOfTime)
    first = [0.1, -0.2, 0.3]
    with torch.no_grad():
        probs, _, n, read = reasoner.think(ids, 3, "choice", first, reasoner.decision_end(), 0.0)
        want, _ = reasoner.read(model.decider.hidden(reasoner.read_ids(reasoner.prompt(ids), full[:1])), 3, "choice",
                                first)
    assert read and n == 1 and probs == pytest.approx(want, abs=1e-6)
    model.decide(STATE, {"route": REQUEST["route"]})
    assert model.decider.last["thought"] and not model.decider.last["dropped"]
    assert model.decider.last["output_tokens"] == 1
    off = load(folder, reasoning=True, think_share=1.0, decision_seconds=1e-6)
    off.decide(STATE, {"route": REQUEST["route"]})               # no time to start: nothing written, nothing read
    assert off.decider.last["dropped"] and off.decider.last["output_tokens"] == 0


def test_vllm_engine_writes_the_reasoning(tiny, monkeypatch):
    """--reasoning-engine vllm: the generator (vLLM, here a stand-in) is built before the decision model with the base
    model and the memory share, writes the reasoning (cut at the first stop token), and no adapter hooks are needed."""
    import jeff.reasoning as R
    calls = []

    class FakeVLLM:
        def __init__(self, base, revision, tokenizer, max_len, memory, max_seqs=1):
            calls.append((base, revision, max_len, memory))

        def generate_many(self, prompts, budget, stops):
            return [[ids[-1]] * 3 + [stops[0], 7] for ids in prompts]    # three tokens, a stop token, anything after

    monkeypatch.setattr(R, "VLLMGenerator", FakeVLLM)
    folder, _ = tiny("gemma", "full")
    model = load(folder, reasoning=True, think_share=1.0, reasoning_engine="vllm", vllm_memory=0.4, vllm_base="base-x")
    assert calls == [("base-x", None, 8192 + 4 + 64, 0.4)]
    assert model.reasoning_engine == "vllm" and model.decider.reasoner.delta is None
    answer = model.decide(STATE, {"route": REQUEST["route"]})["route"]
    assert model.decider.last["thought"] and model.decider.last["output_tokens"] == 3
    assert sum(answer["probabilities"].values()) == pytest.approx(1.0, abs=1e-6)
    model.warmup()                                         # warms the generator too, not counted
    assert model.decider.reasoner.served == [1, 3]
    with pytest.raises(ValueError, match="reasoning_engine"):
        load(folder, reasoning=True, reasoning_engine="tgi")

             "urgent": {"type": "noul", "instructions": "Urgent?"},

class StandInModel:
    """JeffModel's interface: every option gets probability 1/k, or decide() raises `error`."""
    name = "stand-in"

    def __init__(self, error: Exception | None = None):
        self.error, self.rule, self.decider, self.last = error, {}, self, {}

    def start_request(self):
        pass

    def row(self, state, question, key="q"):
        return T.question_row(state, question, key)

    def decide(self, row):
        if self.error:
            raise self.error
        k = len(row["options"])
        return [1 / k] * k, [0.0] * k, 100, 0.01

    def answer(self, qtype, option_ids, probabilities):
        return served_answer(qtype, option_ids, probabilities, self.rule)


@pytest.fixture
def start():
    servers = []

    def run(model) -> str:
        httpd = HTTPServer(("127.0.0.1", 0), make_handler(model, {"model": model.name}))
        threading.Thread(target=httpd.serve_forever, daemon=True).start()
        servers.append(httpd)
        return f"http://127.0.0.1:{httpd.server_address[1]}"
    yield run
    for httpd in servers:
        httpd.shutdown()
        httpd.server_close()


def call(url: str, body=None, path: str = "/v1/systemone") -> tuple[int, dict]:
    data = None if body is None else body if isinstance(body, bytes) else json.dumps(body).encode()
    try:
        with urllib.request.urlopen(urllib.request.Request(url + path, data=data), timeout=10) as r:
            return r.status, json.loads(r.read())
    except urllib.error.HTTPError as error:
        return error.code, json.loads(error.read())

def softmax(z: list[float]) -> list[float]:
    e = [math.exp(v - max(z)) for v in z]
    return [v / sum(e) for v in e]


@pytest.mark.parametrize("qtype, ids, key", [("choice", ["a", "b", "c"], "choice_t"), ("score", ["0", "1", "2"], "score_t")])
def test_temperature_divides_the_logits(qtype, ids, key):
    z = [1.0, 2.5, -0.3]
    out = T.apply_rule(qtype, dict(zip(ids, softmax(z))), {key: 1.5})
    assert [out[i] for i in ids] == pytest.approx(softmax([v / 1.5 for v in z]))
