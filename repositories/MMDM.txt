<h1 align="center">MMDM: Measuring Massive Multitask Decision Making</h1>

<p align="center">
  <a href="https://arxiv.org/abs/2611.14309">📄 Paper</a> ·
  <a href="https://mmdm-benchmark.github.io">🌐 Homepage</a> ·
  <a href="https://huggingface.co/datasets/shenjunhao/mmdm">🤗 Dataset</a> ·
  <a href="https://mmdm-benchmark.github.io/#leaderboard">🏆 Leaderboard</a>
</p>

The official evaluation toolkit for **MMDM**, a benchmark for text-based System-1 Decision Models. Evaluate single-choice, multiple-correct-option, soft-distribution, and Score tasks with one scoring protocol. See the [homepage](https://mmdm-benchmark.github.io) for the benchmark and results.

## Install

Python 3.11+ on Linux or macOS (Windows: WSL).

```bash
git clone https://github.com/mmdm-benchmark/mmdm.git
cd mmdm
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Quick start

Check the first 20 questions without an API key:

```bash
mmdm-eval --output runs/preflight \
  --context-limit 32768 --service-overhead 1024 \
  --prepare-only --limit 20
```

The toolkit **automatically downloads and caches the dataset and tokenizer**. Data is pinned to a Hugging Face commit and checksum-verified. The default Qwen3.5-4B tokenizer is a proxy for input budgeting; only its tokenizer file is downloaded. Set the context budget for the service you evaluate.

### Evaluate an API

```bash
export JEV_API_KEY="your-key"
bash examples/evaluate_jev.sh
```

For Microsoft Decision-1:

```bash
export OPENROUTER_API_KEY="your-key"
bash examples/evaluate_microsoft.sh
```

Both scripts evaluate the full dataset with 16 concurrent requests. Repeat the same command to resume from the cache. For a short run, append `--limit 20` and use a separate output directory. Override `--model` and `--expected-model` together to evaluate another version.

### Evaluate your model

For a service implementing the typed decision API:

```bash
mmdm-eval --provider custom \
  --endpoint http://127.0.0.1:8000/v1/systemone --model my-model \
  --tokenizer /path/to/tokenizer.json --tokenizer-role provider \
  --context-limit 32768 --service-overhead 1024 \
  --option-cap 1024 --output runs/my-model
```

For any other inference interface, write one prediction per line and run the scorer:

```json
{"id": "question-id", "probabilities": [0.1, 0.7, 0.2]}
```

Probabilities follow the dataset's option order. A mapping from option IDs to probabilities also works. [This runnable example](examples/predict.py) shows where to plug in your model; its default predictor is a uniform baseline.

```bash
python examples/predict.py --output runs/uniform/predictions.jsonl
mmdm-score --predictions runs/uniform/predictions.jsonl --output runs/uniform-score
```

## Data and outputs

Use `--input /path/to/mmdm.jsonl` for a local dataset, or pre-download with `mmdm-download --with-tokenizer`. [Hugging Face](https://huggingface.co/datasets/shenjunhao/mmdm) also provides the dataset in Parquet format.

Each API run writes `summary.json` (overall and per-category scores), `scored.jsonl`, `predictions.jsonl`, and a resumable request cache. `identity.json` records the data, code, tokenizer, model, and context configuration.

- **Single choice:** hard accuracy.
- **Multiple correct options:** exact Top-N set match and probability balance.
- **Soft targets:** Brier score and total variation.
- **Score tasks:** expected-score MAE and normalized MAE.

The evaluator preserves the question, every option, and every criterion. It applies deterministic head–tail truncation to `state` when needed. Larger independent catalogs use hierarchical selection when they exceed the configured option cap. [Evaluation details and API contract →](docs/evaluation.md)

# Evaluation reference

## Inputs and downloads

`mmdm-eval`, `mmdm-score`, and `mmdm-download` share the published JSONL release. The default revision is pinned in `mmdm_eval/download.py`; its SHA-256 is checked against the release manifest and the package's expected checksum. Downloads use the standard Hugging Face cache. `--cache-dir` selects another cache; `HF_HUB_OFFLINE=1` reuses already-cached assets offline.

Pass `--input FILE.jsonl` to use a local copy. Dataset files stay unchanged. `--tokenizer` accepts a local `tokenizer.json`, its directory, or a Hugging Face model ID; `--tokenizer-revision` pins a model revision. `--dataset-revision` accepts a full dataset commit SHA. A run records the actual data and tokenizer hashes.

`--limit N` selects the first N rows for integration checks. Omit it for the full benchmark. Limited runs have their own identity and output directory.

## API adapters

| Provider | Endpoint | Credential environment variable |
| --- | --- | --- |
| `jev` | `https://api.typesafe.ai/v1/systemone` | `JEV_API_KEY` |
| `microsoft` | `https://openrouter.ai/api/alpha/decisions` | `OPENROUTER_API_KEY` |
| `custom` | `--endpoint` | optional `--api-key-env VARIABLE` |

The built-in model pins are Jev `jev-1.14.0` and Microsoft `microsoft/microsoft-decision-1` (expected response version `microsoft/microsoft-decision-1-20261009`). Set both `--model` and `--expected-model` to change them. For `custom`, the expected response model defaults to `--model`.

Custom endpoints use the same typed request and response shape as [Jev's decision API](https://docs.typesafe.ai/introduction/quickstart):

```json
{
  "model": "my-model",
  "state": "The current situation...",
  "questions": {
    "decision": {
      "type": "choice",
      "instructions": "Which action should be taken?",
      "criteria": {"Action A": "When A applies", "Action B": "When B applies"}
    }
  }
}
```

```json
{
  "model": "my-model",
  "answers": {
    "decision": {"type": "choice", "probabilities": {"Action A": 0.8, "Action B": 0.2}}
  }
}
```

`common.wire` handles the benchmark's Choice, Noul, and Score primitives; `common.parse_native` aligns returned probabilities with the original option order. Noul returns `answers.decision.noul`; Score returns a probability dictionary over string indices `"0"`, `"1"`, etc. Inspect these two functions when implementing an adapter. OpenAI chat-completion endpoints use a different contract; integrate them through the [prediction example](../examples/predict.py) and `mmdm-score`.

Only `state`, `question`, `options`, `task`, and `score_values` enter model requests. Reference answers and category metadata stay in the evaluator.

## Context and candidate catalogs

Declare `--context-limit`, `--service-overhead`, and optionally `--output-reserve`. The compact serialized API request must fit within:

```text
available = context_limit - service_overhead - output_reserve
```

The default tokenizer is Qwen3.5-4B, recorded as a **proxy**. For a service's own tokenizer, use `--tokenizer PATH_OR_MODEL --tokenizer-role provider`. The example scripts use a 32,768-token evaluation budget and a 1,024-token service allowance; these are run settings. Adjust them for your endpoint.

The context adapter preserves all fixed input fields, then retains approximately equal token-boundary portions from the start and end of the original Unicode `state`, with an omission marker. It recounts the complete request. If the fixed fields alone exceed the budget, the result is `fixed_fields_exceed_budget`; if the provider rejects the input length, it is `provider_context_capacity`. Both appear in coverage and failure counts.

For independent catalog tasks above `--option-cap`, the evaluator partitions options deterministically, keeps the top N from each group, and repeats until a final group fits. N is one for single choice and the reference set size for multiple-correct-option evaluation. The API receives neither gold IDs nor N. Every original option participates; all groups share the same budgeted state. Cross-option logic and soft-distribution tasks require a native full-catalog response. The complete catalog is budgeted before grouping.

Native and grouped results are reported separately. Grouped final probabilities are conditional on the surviving set, so full-catalog Brier and Score MAE are computed only for native responses.

## Scoring

- **Hard single accuracy:** the unique highest-probability option must be correct. A tie for first place is incorrect.
- **Hard-set accuracy:** all gold members must rank strictly above all nonmembers. N is the number of gold members; a tie across the boundary is incorrect.
- **Top-N balance:** probabilities within the predicted top N are renormalized and compared with a uniform distribution. One means equal allocation; zero means all top-N mass is on one member. Balance and set accuracy are separate metrics.
- **Soft Brier:** sum of squared errors over options, averaged across valid questions. Lower is better.
- **Soft total variation:** half the sum of absolute probability errors.
- **Score MAE:** absolute difference between predicted and reference expected numeric scores. Normalized MAE divides by the score-scale range.

Hard `accuracy_all` includes failed or missing predictions as incorrect; `accuracy_valid` uses valid responses. Distribution metrics include their valid counts. Report coverage with the scores. Probabilities must be finite, nonnegative, at most one, and sum to one within 0.02; accepted rounding drift is renormalized.

## Offline predictions

`mmdm-score` joins predictions by `id`, counts missing and malformed probabilities as invalid, and rejects duplicate or unknown IDs. Probabilities may be an ordered array or a complete dictionary keyed by option ID. Optional `actor_sha256` binds a prediction to its input. A failed request can be recorded as `{"id": "...", "ok": false, "status": "request_error"}`.

The offline scorer accepts native full-distribution predictions. Grouped API runs are scored directly by `mmdm-eval`, which includes their selection trace in `predictions.jsonl`.

## Resume and files

Repeat a command with the same output directory to resume. Successful predictions and HTTP responses are cached; transient failures are retried. A model, dataset, code, tokenizer, budget, seed, or selection change requires a new output directory.

| File | Contents |
| --- | --- |
| `identity.json` | Dataset/code/tokenizer hashes and run configuration |
| `predictions.jsonl` | Probabilities or grouping traces, context accounting and API usage |
| `calls.sqlite` | Request and response cache, excluding authorization headers |
| `scored.jsonl` | Per-question metrics |
| `summary.json` | Overall, category and context-view aggregates |
| `status.json` | Progress, valid count, attempts and cache hits |
| `COMPLETE.json` / `BLOCKED.json` | Run outcome |

`--prepare-only` writes `context-audit.jsonl` and `context-summary.json` without inference calls. Use a separate output directory for the subsequent evaluation. Authentication or quota errors stop the run with a nonzero exit status; resume after resolving them.

## Checks

```bash
python -m unittest discover -s tests -v
```

Tests cover label isolation, Unicode truncation, protected fields, grouping, resume, download checksums, score denominators, and API integration with a local fixture service.

"""Minimal model integration. Replace predict() with your model's inference call."""
import argparse
from pathlib import Path

from mmdm_eval.common import actor, digest, dump, rows, valid_p
from mmdm_eval.download import resolve_dataset


def predict(request):
    # This runnable baseline assigns uniform probability. Only model-visible
    # fields are provided; replace this function to call your model.
    count = len(request["options"])
    return [1 / count] * count


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--input", help="local dataset JSONL; otherwise auto-download")
    parser.add_argument("--output", required=True)
    args = parser.parse_args()
    source = resolve_dataset(args.input)
    output = Path(args.output)
    output.parent.mkdir(parents=True, exist_ok=True)
    with output.open("x", encoding="utf-8") as stream:
        for row in rows(source):
            request = actor(row)
            probabilities = valid_p(predict(request), len(request["options"]))
            stream.write(dump(dict(id=row["id"], actor_sha256=digest(request),
                                   probabilities=probabilities)) + "\n")
    print(output)


if __name__ == "__main__":
    main()

"""Resumable decision API transport; keys are read only from the environment."""
import asyncio
import json
import os
import sqlite3
import time
import urllib.error
import urllib.request

from .common import digest, dump

PROVIDERS = {
    "jev": {"url": "https://api.typesafe.ai/v1/systemone", "model": "jev-1.14.0",
            "expected_model": "jev-1.14.0", "key_env": "JEV_API_KEY"},
    "microsoft": {"url": "https://openrouter.ai/api/alpha/decisions",
                  "model": "microsoft/microsoft-decision-1",
                  "expected_model": "microsoft/microsoft-decision-1-20261009",
                  "key_env": "OPENROUTER_API_KEY"},
    "custom": {"url": None, "model": None, "expected_model": None, "key_env": None},
}


class ApiError(RuntimeError):
    def __init__(self, status, key, context=False):
        self.status, self.cache_key, self.context = status, key, context
        super().__init__(f"http_{status}_cache_{key}")


class ProviderBlocked(ApiError):
    pass


def is_context_error(status, response):
    text = dump(response).lower()
    return status == 413 or (status in (400, 422) and any(term in text for term in (
        "max_tokens_exceeded", "context limit", "context length", "maximum context",
        "too many tokens", "limit for the state plus all questions")))


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None


class Client:
    def __init__(self, root, provider, concurrency, run_identity, *, config=None):
        self.config = config or PROVIDERS[provider]
        key_env = self.config["key_env"]
        self.secret = os.environ.get(key_env, "").strip() if key_env else ""
        if key_env and not self.secret:
            raise ValueError("set " + self.config["key_env"])
        self.root = root
        self.identity = run_identity
        self.sem = asyncio.Semaphore(concurrency)
        self.db = sqlite3.connect(root/"calls.sqlite")
        self.db.execute("pragma journal_mode=WAL")
        self.db.execute("create table if not exists calls(key text primary key, request text, response text, status integer, at real)")
        self.db.commit()
        self.attempts = 0
        self.cache_hits = 0
        self.fatal = None

    def post(self, body):
        headers = {"Content-Type": "application/json"}
        if self.secret:
            headers["Authorization"] = "Bearer " + self.secret
        request = urllib.request.Request(
            self.config["url"], data=json.dumps(body, ensure_ascii=False, separators=(",", ":"), allow_nan=False).encode(),
            headers=headers)
        opener = urllib.request.build_opener(NoRedirect())
        try:
            with opener.open(request, timeout=360) as response:
                status, raw = response.status, response.read()
        except urllib.error.HTTPError as exc:
            status, raw = exc.code, exc.read()
        except (urllib.error.URLError, TimeoutError, OSError) as exc:
            return 0, {"error_type": type(exc).__name__}
        try:
            payload = json.loads(raw)
            if not isinstance(payload, dict):
                payload = {"error_type": "non_object_response"}
        except (ValueError, UnicodeError):
            payload = {"error_type": "non_json_response"}
        return status, payload

    async def call(self, body):
        key = digest({"run_identity": self.identity, "endpoint": self.config["url"], "body": body})
        old = self.db.execute("select response,status from calls where key=?", (key,)).fetchone()
        if old:
            response, status = json.loads(old[0]), old[1]
            if status == 200 and not response.get("error") and not response.get("error_type"):
                self.cache_hits += 1
                return response, key
            if is_context_error(status, response):
                raise ApiError(status, key, context=True)
        for attempt in range(5):
            async with self.sem:
                if self.fatal:
                    raise self.fatal
                status, response = await asyncio.to_thread(self.post, body)
                self.attempts += 1
                self.db.execute("insert or replace into calls values(?,?,?,?,?)",
                                (key, dump(body), dump(response), status, time.time()))
                self.db.commit()
                with (self.root/"http-attempts.jsonl").open("a") as f:
                    f.write(dump(dict(cache_key=key, status=status, at=time.time()))+"\n")
                if status == 200 and not response.get("error") and not response.get("error_type"):
                    return response, key
                if status in (401, 402, 403, 404) or 300 <= status < 400:
                    self.fatal = ProviderBlocked(status, key)
                    raise self.fatal
                if status not in (0, 408, 409, 425, 429, 500, 502, 503, 504, 529):
                    raise ApiError(status, key, context=is_context_error(status, response))
            if attempt < 4:
                await asyncio.sleep(min(60, 2**attempt))
        raise ApiError(status, key)

    def close(self):
        self.db.close()

"""MMDM JSON, actor and typed decision API contract."""
import hashlib
import json
import math
import os
from pathlib import Path

def dump(x):
    return json.dumps(x, sort_keys=True, ensure_ascii=False, allow_nan=False)

def digest(x):
    return hashlib.sha256(dump(x).encode()).hexdigest()

def file_sha(p):
    h = hashlib.sha256()
    with Path(p).open('rb') as f:
        for block in iter(lambda: f.read(1024 * 1024), b''):
            h.update(block)
    return h.hexdigest()

def save(p, value):
    p = Path(p)
    p.parent.mkdir(parents=True, exist_ok=True)
    t = p.with_name(p.name + f'.{os.getpid()}.partial')

def actor(r):
    return {k: r[k] for k in ['state', 'question', 'options', 'task', 'score_values'] if k in r}

def gold_kind(q):
    assert q and all(isinstance(x, (int, float)) and not isinstance(x, bool) and math.isfinite(x) and 0 <= x <= 1 for x in q)
    assert abs(math.fsum(q) - 1) < 1e-6
    return 'hard' if q.count(1.0) == 1 and q.count(0.0) == len(q)-1 else 'soft'

def valid_p(p, n):
    assert isinstance(p, list) and len(p) == n
    assert all(isinstance(x, (int, float)) and not isinstance(x, bool) and math.isfinite(x) and 0 <= x <= 1 for x in p)
    s = math.fsum(p)
    assert s > 0 and abs(s - 1) <= .020000001
    return [x/s for x in p]

def wire(r, model):
    opts = r['options']; names = [o['name'] for o in opts]
    kind = r['task']; q = {'type': kind, 'instructions': r['question']}
    if kind == 'noul' and [x.lower() for x in names] == ['false', 'true']:
        keys = ['no', 'yes']
        q['criteria'] = {k: o['criteria'] for k, o in zip(['false', 'true'], opts) if o.get('criteria') is not None}
    elif kind == 'score' and len(opts) <= 10:
        assert len(r['score_values']) == len(opts)
        keys = list(map(str, range(len(opts))))
        q['criteria'] = [dict(name=o['name'], criteria=o.get('criteria'), score_value=v) for o, v in zip(opts, r['score_values'])]
    else:
        q['type'] = 'choice'; keys = names if len(set(names)) == len(names) else [o['id'] for o in opts]
        q['criteria'] = {}
        for i, (k, o) in enumerate(zip(keys, opts)):
            c = o.get('criteria')
            if keys != names or kind == 'score':
                c = dict(name=o['name'], criteria=c)
                if kind == 'score': c['score_value'] = r['score_values'][i]
            q['criteria'][k] = c
    return {'state': r['state'], 'questions': {'decision': q}, 'model': model}, keys

def parse_native(body, keys, response):
    a = response['answers']['decision']
    if a.get('type') != body['questions']['decision']['type']:
        raise ValueError('response_type_mismatch')
    if a['type'] == 'noul':
        p = a['noul']
        if isinstance(p, bool): raise ValueError('boolean_probability')
        return valid_p([1-float(p), float(p)], 2)
    p = a['probabilities']
    if set(p) != set(keys): raise ValueError('option_key_mismatch')
    return valid_p([p[k] for k in keys], len(keys))

"""Gold-blind, deterministic state-only context adaptation.

The counter measures the complete provider request, including fixed fields.
Service and output allowances are explicit run parameters, never inferred from
the benchmark's stored length estimates. Original strings are sliced by Python
character offsets; token decoding cannot corrupt a partial UTF-8 character.
"""
from copy import deepcopy
from dataclasses import asdict, dataclass

from .common import actor, digest, file_sha

PROTOCOL = "mmdm-state-head-tail-v1"
MARKER = "\n\n[... middle of state omitted ...]\n\n"


class FixedFieldsTooLong(ValueError):
    def __init__(self, metadata):
        self.metadata = metadata
        super().__init__("question/options/criteria and overhead exceed context budget")


@dataclass(frozen=True)
class Budget:
    context_limit: int
    service_overhead: int
    output_reserve: int = 0

    def __post_init__(self):
        values = asdict(self)
        if any(type(v) is not int for v in values.values()):
            raise ValueError("context budgets must be integers")
        if self.context_limit < 1 or self.service_overhead < 0 or self.output_reserve < 0:
            raise ValueError("invalid context budget")
        if self.available < 1:
            raise ValueError("service/output reserves exhaust context budget")

    @property
    def available(self):
        return self.context_limit - self.service_overhead - self.output_reserve


class JsonTokenizerCounter:
    """Local estimate of compact wire JSON; provider hidden tokens are reserved.

Use the provider tokenizer when available. If a proxy tokenizer is used, declare
it in the run and supply an appropriate overhead. Unknown provider capacity is
never silently replaced with 65,535 or a character-based approximation.
"""
    def __init__(self, tokenizer_path, render, *, tokenizer_role):
        from tokenizers import Tokenizer
        import tokenizers
        self.tokenizer = Tokenizer.from_file(str(tokenizer_path))
        # A tokenizer.json may itself contain truncation or padding settings.
        self.tokenizer.no_truncation()
        self.tokenizer.no_padding()
        self.render = render
        self.identity = dict(tokenizer_sha256=file_sha(tokenizer_path),
                             tokenizer_role=tokenizer_role,
                             tokenizers_version=tokenizers.__version__,
                             serialization="compact-wire-json-utf8-v1",
                             special_tokens=False)

    def text_tokens(self, text):
        return len(self.tokenizer.encode(text, add_special_tokens=False).ids)

    def boundaries(self, text):
        # Offset sets keep slices on original-text boundaries, including Unicode.
        encoding = self.tokenizer.encode(text, add_special_tokens=False)
        return sorted({0, len(text), *(end for start, end in encoding.offsets if end > start)})

    def __call__(self, value):
        import json
        body = self.render(value)
        text = json.dumps(body, ensure_ascii=False, separators=(",", ":"), allow_nan=False)
        return self.text_tokens(text)


def adapt_state(row, counter, budget):
    """Return a separate actor view plus complete accounting, without labels.

Always recount the full rendered request. Fixed-field subtraction provides a
budget report, not an assumption that separately tokenized fields are additive.
Head/tail retain approximately equal numbers of token boundaries; an odd unit
goes to the head. The binary search need not find a maximal BPE packing: every
accepted candidate is independently measured and never exceeds the budget.
"""
    original = deepcopy(actor(row))
    state = original["state"]
    if not isinstance(state, str):
        raise TypeError("state must be text")
    fixed = {k: v for k, v in original.items() if k != "state"}
    empty = {**original, "state": ""}
    total, fixed_tokens = counter(original), counter(empty)
    meta = dict(protocol=PROTOCOL, budget=asdict(budget), counter=counter.identity,
                available_input_tokens=budget.available, fixed_request_tokens=fixed_tokens,
                nominal_state_token_budget=budget.available-fixed_tokens,
                original_input_tokens=total, original_state_tokens=counter.text_tokens(state),
                original_actor_sha256=digest(original), protected_fields_sha256=digest(fixed),
                original_state_sha256=digest(state), original_state_chars=len(state))
    # Check the actual original first; tokenization is not additive at boundaries.
    if total <= budget.available:
        view = original
        ranges = [[0, len(state)]] if state else []
        marker_used = False
    else:
        if fixed_tokens > budget.available:
            raise FixedFieldsTooLong({**meta, "status": "fixed_fields_exceed_budget"})
        boundaries = counter.boundaries(state)
        if not boundaries or boundaries[0] != 0 or boundaries[-1] != len(state):
            raise ValueError("counter must expose original-text boundaries")
        units = len(boundaries)-1
        view, ranges, marker_used = empty, [], False
        # A marker is counted only if a nonempty head or tail can also fit.
        lo, hi = 1, max(0, units-1)
        while lo <= hi:
            keep = (lo+hi)//2
            head, tail = (keep+1)//2, keep//2
            left, right = boundaries[head], boundaries[units-tail]
            candidate = {**original, "state": state[:left]+MARKER+state[right:]}
            if counter(candidate) <= budget.available:
                view = candidate
                ranges = [[0, left]] + ([[right, len(state)]] if tail else [])
                marker_used = True
                lo = keep+1
            else:
                hi = keep-1
    used = counter(view)
    if used > budget.available:
        raise AssertionError("adapted request exceeds configured budget")
    if {k: v for k, v in view.items() if k != "state"} != fixed:
        raise AssertionError("protected fields changed")
    meta.update(truncated=view["state"] != state, input_tokens=used,
                input_tokens_with_reserves=used+budget.service_overhead+budget.output_reserve,
                state_tokens=counter.text_tokens(view["state"]), state_chars=len(view["state"]),
                kept_original_char_ranges=ranges,
                retained_original_chars=sum(b-a for a, b in ranges),
                marker_used=marker_used, effective_actor_sha256=digest(view),
                effective_state_sha256=digest(view["state"]), status="prepared")
    return view, meta

def resolve_dataset(path=None, *, cache_dir=None, revision=DATASET_REVISION):
    if path is not None:
        local = Path(path).expanduser().resolve()
        if not local.is_file():
            raise FileNotFoundError(f"Dataset file does not exist: {local}")

    if not re.fullmatch(r"[0-9a-f]{40}", revision):

    from huggingface_hub import hf_hub_download
    common = dict(repo_id=DATASET, repo_type="dataset", revision=revision, cache_dir=cache_dir)
    path = Path(hf_hub_download(filename="mmdm.jsonl", **common))

        raise ValueError("Published release manifest does not match the pinned dataset")

        raise FileNotFoundError(f"Tokenizer file does not exist: {local}")

"""Deterministic, gold-blind hierarchical top-k selection.

Scores are compared only within a request. Final probabilities are conditional
on the final candidate set, never a distribution over the original catalog.
"""
import asyncio
import math
from .common import digest, dump, valid_p

PROTOCOL = 'hierarchical-choice-v1'
TOL = 1e-12


class ContextCapacityError(RuntimeError):
    pass


def ordered(ids, seed, case_key, path):
    return sorted(ids, key=lambda x: (digest([PROTOCOL, seed, case_key, path, x]), x))


def partition(ids, cap):
    """Contiguous batches, each bounded by cap; no dropped tail."""
    return [ids[i:i+cap] for i in range(0,len(ids),cap)]


def rank(ids, p, k):
    # ids were ordered with a fixed, gold-independent seed.
    ix = sorted(range(len(ids)), key=lambda i: (-p[i], i))
    tie = len(ids) > k and abs(p[ix[k-1]] - p[ix[k]]) <= TOL
    return [ids[i] for i in ix[:k]], tie


async def select_hierarchical(actor, query, *, cap=255, k=1, seed=20261015):
    """query(actor_subset, path) -> (normalized probabilities, call metadata).

This function never receives labels. k is the reference cardinality for the
existing oracle-N multiselect protocol. The API is not given gold IDs or k.
query may raise ContextCapacityError for an explicit provider size rejection.
"""
    opts = actor['options']; ids = [o['id'] for o in opts]
    if len(ids) < 2 or len(set(ids)) != len(ids):
        raise ValueError('invalid_option_ids')
    if not 1 <= k < cap or k >= len(ids):
        raise ValueError('require_1_le_k_lt_cap_and_catalog_size')
    byid = dict(zip(ids, opts)); case_key = digest(actor); trace = []

    # Large tool documentation can exceed context capacity even with k+1
    # candidates. Probe the longest description plus k short descriptions
    # before expanding a costly tree. This is only a capacity check; its scores
    # never influence selection. A failed probe is reported, not truncated.
    sizes = {x:len(dump(byid[x])) for x in ids}
    longest = max(ids,key=lambda x:(sizes[x],x))
    if sizes[longest] > 32000:
        shortest = sorted((x for x in ids if x!=longest),key=lambda x:(sizes[x],x))[:k]
        members = ordered([longest,*shortest],seed,case_key,'context_probe')
        subset = {**actor,'options':[byid[x] for x in members]}
        try:
            p,meta = await query(subset,'context_probe')
            valid_p(p,len(members))
        except ContextCapacityError as exc:
            raise ContextCapacityError('minimal_cardinality_probe_exceeds_context') from exc
        trace.append(dict(path='context_probe',kind='capacity_probe',members=members,**meta))

    async def visit(members, path, depth=0):
        if depth > 32:
            raise ContextCapacityError('context_reduction_depth_limit')
        members = ordered(members, seed, case_key, path)
        if len(members) <= k:
            trace.append(dict(path=path,kind='carry',members=members,selected=members))
            return dict(selected=members, final_ids=members, final_probabilities=None,
                        boundary_tie=False)
        batch_cap = cap
        if len(members) <= cap:
            subset = {**actor, 'options':[byid[x] for x in members]}
            try:
                p, meta = await query(subset, path)
                p = valid_p(p, len(members))
                winners, tie = rank(members, p, k)
                trace.append(dict(path=path,kind='decision',members=members,
                                  probabilities=p,selected=winners,boundary_tie=tie,
                                  **meta))
                return dict(selected=winners,final_ids=members,
                            final_probabilities=p,boundary_tie=tie)
            except ContextCapacityError as exc:
                trace.append(dict(path=path,kind='context_split',members=members,
                                  reason=str(exc)))
                # With <=k+1 options any top-k reduction must compare the entire
                # remaining set. Do not silently truncate descriptions or rank
                # scores from unrelated requests to force an answer.
                if len(members) <= k+1:
                    raise ContextCapacityError('minimum_comparison_exceeds_context') from exc
                batch_cap = max(k+1, math.ceil(len(members)/2))
        batches = partition(members, batch_cap)
        children = await asyncio.gather(*(visit(g, path+'.'+str(i), depth+1)
                                          for i,g in enumerate(batches)),
                                        return_exceptions=True)
        # Drain in-flight siblings before returning an error or taking a snapshot.
        for child in children:
            if isinstance(child, BaseException):
                raise child
        survivors = [x for child in children for x in child['selected']]
        if len(survivors) >= len(members):
            raise ContextCapacityError('reduction_cannot_progress')
        return await visit(survivors, path+'.final', depth+1)

    result = await visit(ids, 'r0')
    result.update(protocol=PROTOCOL,cap=cap,k=k,seed=seed,original_option_count=len(ids),
                  probability_scope='final_survivor_set_only',
                  trace=sorted(trace,key=lambda x:x['path']),
                  intermediate_boundary_ties=sum(x.get('boundary_tie',False) for x in trace))
    return result


def score_selection(row, result):
    """Reference-dependent scoring lives entirely outside the selection path."""
    is_set = row.get('label_semantics') == 'set_hard' or row['task']=='multichoice'
    gold = set(row['correct_option_ids']) if is_set else {
        row['options'][row['gold'].index(1.0)]['id']}
    hit = set(result['selected']) == gold and not result['boundary_tie']
    final = set(result['final_ids'])
    p = result['final_probabilities']; k = result['k']
    top = sorted(p,reverse=True)[:k]; mass = math.fsum(top)
    balance = 1.0 if k==1 else 1 - (
        .5*math.fsum(abs(x/mass-1/k) for x in top))/(1-1/k)
    # This stricter sensitivity statistic flags a gold-containing cutoff tie
    # even if the fixed tie break happened to keep that gold option.
    exposed = False
    for event in result['trace']:
        if event.get('boundary_tie') and set(event['members']) & gold:
            cutoff = sorted(event['probabilities'],reverse=True)[k-1]
            exposed |= any(x in gold and abs(v-cutoff)<=TOL
                           for x,v in zip(event['members'],event['probabilities']))
    return dict(hard_accuracy=None if is_set else float(hit),
                topn_all_hit=float(hit) if is_set else None,
                final_topn_balance=balance if is_set else None,
                final_gold_survival=len(gold & final)/len(gold),
                gold_exposed_to_cutoff_tie=exposed,
                strict_tie_safe_correct=float(hit and not exposed),
                full_catalog_brier=None,full_catalog_score_mae=None)

    return dict(rows=len(vs),valid=len(good),coverage=len(good)/len(vs) if vs else None,

        else:
            k = len(row["correct_option_ids"]) if label_kind(row) == "hard_set" else 1
            if not 1 <= k < cap:
                record["status"] = "unsupported_grouping"
                return record
            result = await select_hierarchical(effective, query, cap=cap, k=k, seed=seed)
            record.update(result=result, metrics=score_selection(row, result))
        record.update(ok=True, status="complete")
    except FixedFieldsTooLong as exc:
        record.update(status="fixed_fields_exceed_budget", context=exc.metadata)
    except ProviderBlocked:
        raise
    except ApiError as exc:
        # A provider rejection remains visible. No answer-dependent shortening or
        # retry-driven budget changes are used to select a favorable view.
        record.update(status="provider_context_capacity" if exc.context else "request_error",
                      error=str(exc), cache_key=exc.cache_key, http_status=exc.status)
    except ContextCapacityError as exc:
        record.update(status="context_capacity", error=str(exc))
    except (ValueError, KeyError, TypeError, AssertionError) as exc:
        record.update(status="protocol_error", error=type(exc).__name__+": "+str(exc)[:200])
    finally:
        record["wall_s"] = time.monotonic()-start
    return record


def report(data, predictions, identity):
    values = [score(r, predictions[r["id"]]) for r in data if r["id"] in predictions]
    context_groups = {}
    for name, predicate in (("full_input", lambda c: c.get("truncated") is False),
                            ("truncated_state", lambda c: c.get("truncated") is True),
                            ("fixed_fields_exceed_budget", lambda c: c.get("status") == "fixed_fields_exceed_budget")):
        context_groups[name] = summarize([v for v in values if predicate(predictions[v["id"]].get("context", {}))])
    return dict(identity=identity, planned=len(data), processed=len(values), pending=len(data)-len(values),
                overall=summarize(values), by_context=context_groups,
                context_statuses=dict(Counter(p.get("context", {}).get("status", "unknown") for p in predictions.values())),
                categories={c: summarize([v for v in values if v["category"] == c])
                            for c in sorted({v["category"] for v in values})})

"""Score model probability files against MMDM, including missing and invalid predictions."""
import argparse
from pathlib import Path

from .common import actor, digest, dump, file_sha, jsonl, rows, save, valid_p
from .download import DATASET_REVISION, resolve_dataset

def score_predictions(data, predictions):
    """Join by question ID; probabilities follow option order or use option-ID keys."""
    by_id = {row["id"]: row for row in data}
    if not data or len(by_id) != len(data):
        raise ValueError("Dataset must contain unique question IDs")
    submitted = {}
    for prediction in predictions:
        rid = prediction.get("id")
        if rid not in by_id:
            raise ValueError(f"Unknown prediction ID: {rid}")
        if rid in submitted:
            raise ValueError(f"Duplicate prediction ID: {rid}")
        submitted[rid] = prediction
    scored = []
    for rid, row in by_id.items():
        supplied = submitted.get(rid)
        record = dict(ok=False, mode="native", status="missing_prediction")
        if supplied is not None:
            if supplied.get("mode", "native") != "native":
                raise ValueError("Grouped runs are scored by mmdm-eval; use that run's summary.json")
            record["status"] = "invalid_prediction"
            if supplied.get("actor_sha256", digest(actor(row))) != digest(actor(row)):
                raise ValueError(f"Prediction input hash mismatch: {rid}")
            if supplied.get("ok", True) is False:
                record["status"] = supplied.get("status", "request_error")
            else:
                try:
                    p = supplied["probabilities"]
                    if isinstance(p, dict):
                        ids = [o["id"] for o in row["options"]]
                        if set(p) != set(ids):
                            raise ValueError("Probability keys must equal option IDs")
                        p = [p[oid] for oid in ids]
                    p = valid_p(p, len(row["options"]))
                    record.update(ok=True, status="complete", probabilities=p)
                except (ValueError, TypeError, KeyError, AssertionError, OverflowError):
                    pass
        scored.append(score(row, record))
    return scored


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--input", help="local dataset JSONL; default: download pinned MMDM")
    parser.add_argument("--predictions", required=True, help="JSONL with id and probabilities")
    parser.add_argument("--output", required=True, help="new output directory")
    parser.add_argument("--cache-dir")
    parser.add_argument("--dataset-revision", default=DATASET_REVISION)
    args = parser.parse_args(argv)
    root = Path(args.output)
    if root.exists() and any(root.iterdir()):
        parser.error("--output must be empty")
    source = resolve_dataset(args.input, cache_dir=args.cache_dir, revision=args.dataset_revision)
    data = list(rows(source))
    predictions = list(rows(args.predictions))
    values = score_predictions(data, predictions)
    identity = dict(dataset_sha256=file_sha(source), predictions_sha256=file_sha(args.predictions),
                    code={p.name: file_sha(p) for p in sorted(Path(__file__).parent.glob("*.py"))})
    summary = dict(identity=identity, planned=len(data), submitted=len(predictions), overall=summarize(values),
                   categories={c: summarize([v for v in values if v["category"] == c])
                               for c in sorted({v["category"] for v in values})})
    root.mkdir(parents=True, exist_ok=True)
    jsonl(root/"scored.jsonl", values)
    save(root/"summary.json", summary)
    print(dump(summary["overall"]))


if __name__ == "__main__":
    main()

"""Hard-set evaluation for normalized relevance scores, separate from soft gold.

Top-k uses reference cardinality only in the evaluator. It measures ranking, not
the model's ability to predict set size. Native set output is scored separately.
"""
import math


def _ids(values, name):
    if not isinstance(values, (list, tuple)) or not values:
        raise ValueError(name + '_must_be_nonempty')
    if any(not isinstance(x, str) or not x for x in values):
        raise ValueError(name + '_must_contain_string_ids')
    if len(set(values)) != len(values):
        raise ValueError(name + '_has_duplicates')
    return list(values)


def evaluate_hard_set(option_ids, correct_ids, probabilities, *,
                      predicted_ids=None, tie_tolerance=1e-12):
    ids = _ids(option_ids, 'option_ids')
    gold = set(_ids(correct_ids, 'correct_ids'))
    if not gold <= set(ids):
        raise ValueError('unknown_gold_id')
    if len(ids) < 2 or not 0 <= tie_tolerance <= 1e-6:
        raise ValueError('invalid_options_or_tolerance')
    if len(probabilities) != len(ids):
        raise ValueError('probability_count_mismatch')
    p = list(probabilities)
    if any(isinstance(x, bool) or not isinstance(x, (int, float))
           or not math.isfinite(x) or not 0 <= x <= 1 for x in p):
        raise ValueError('invalid_probability')
    if not math.isclose(math.fsum(p), 1.0, rel_tol=0, abs_tol=1e-8):
        raise ValueError('normalized_relevance_distribution_required')
    k = len(gold)
    positive = [v for i, v in zip(ids, p) if i in gold]
    negative = [v for i, v in zip(ids, p) if i not in gold]
    mass = math.fsum(positive)
    margin = min(positive) - max(negative) if negative else None
    # A tie across the boundary cannot pass by option-order tie breaking.
    exact = float(margin > tie_tolerance) if negative else 1.0
    tv = (0.5 * math.fsum(abs(v / mass - 1 / k) for v in positive)
          if mass > 0 else None)
    balance = (1.0 if k == 1 and mass > 0 else
               1 - tv / (1 - 1 / k) if tv is not None else None)
    topn = sorted(p, reverse=True)[:k]
    topn_mass = math.fsum(topn)
    topn_tv = 0.5 * math.fsum(abs(v / topn_mass - 1 / k) for v in topn)
    topn_balance = 1.0 if k == 1 else 1 - topn_tv / (1 - 1 / k)
    q = [1 / k if i in gold else 0.0 for i in ids]
    result = {
        'target_kind': 'hard', 'label_semantics': 'set_hard',
        'probability_semantics': 'normalized_equal_membership_relevance',
        'num_options': len(ids), 'reference_cardinality': k,
        'topn_all_hit': exact, 'topn_balance': topn_balance,
        'primary_metrics': ['topn_all_hit', 'topn_balance'],
        'balance_scope': 'predicted_top_n_normalized_by_its_own_probability_mass',
        'topk_set_exact': exact, 'topk_uses_reference_cardinality': True,
        'boundary_tie': bool(negative and abs(margin) <= tie_tolerance),
        'rank_margin': margin, 'correct_set_mass': mass,
        'within_set_tv_to_uniform': tv, 'within_set_balance': balance,
        'uniform_target_brier': math.fsum((a - b) ** 2 for a, b in zip(p, q)),
        'chance_topk_exact': 1 / math.comb(len(ids), k),
    }
    if predicted_ids is not None:
        if not isinstance(predicted_ids, (list, tuple)):
            raise ValueError('predicted_ids_must_be_list')
        pred = set(predicted_ids)
        if len(pred) != len(predicted_ids) or not pred <= set(ids):
            raise ValueError('invalid_predicted_ids')
        tp = len(pred & gold)
        result.update(native_set_exact=float(pred == gold),
                      native_set_precision=tp / len(pred) if pred else 0.0,
                      native_set_recall=tp / k,
                      native_set_f1=2 * tp / (len(pred) + k),
                      cardinality_error=abs(len(pred) - k))
    return result

class FakeClient:
